Welcome to the GFTGU Setup Guide

This guide will walk you through everything you need to run the Python physics simulation programs from the textbook "Gravity From the Ground Up" by Bernard Schutz. These programs bring the physics from the book to life — they simulate orbits, stellar structures, gravitational fields, and more, right on your own computer.

No programming experience is required. This guide assumes you've never written a line of code. Every step is explained in plain language, and you'll be running your first simulation in about 30–45 minutes.

Here's the plan: you'll install Python (the engine), install a few add-on packages (the tools), install PyCharm (a comfortable workspace), download the programs from the internet, and then open and run them.

The 13 Programs Available

Atmosphere Binary CannonTrajectory EarthOrbit MercPert Multiple Neutron Orbit Planck2 Random2 RelativisticOrbit SphereGravity Star

These programs require two Python packages: NumPy and Matplotlib.

You Will Need

  • A computer running Windows or macOS
  • An internet connection (for downloading software)
  • About 30–45 minutes of your time

Section 1: Install Python

💡

What is Python?

Python is a free programming language that the GFTGU simulation programs are written in. Think of it as the engine that makes the programs run. You won't need to learn Python yourself — you just need it installed so the programs can use it.

Windows Instructions

  1. 1

    Open your web browser and go to python.org/downloads. The site will automatically show the latest version for Windows.

  2. 2

    Click the large yellow "Download Python 3.x.x" button at the top of the page.

  3. 3

    Once downloaded, run the installer by double-clicking the file (usually in your Downloads folder).

  4. 4

    CRITICAL — do not skip this: On the very first screen of the installer, you'll see a checkbox near the bottom labeled "Add Python to PATH".

    ⚠️

    You MUST check this box!

    Check the "Add Python to PATH" box before doing anything else. This allows your computer to find Python when you need it later. If you forget this step, the rest of the guide won't work properly — you'd have to uninstall and reinstall Python.

  5. 5

    After checking the box, click "Install Now".

  6. 6

    Wait for the installation to complete (usually 1–2 minutes), then click Close.

  7. 7

    Verify it works: Open the Start menu, search for "Command Prompt", and open it. Type the following command and press Enter:

    python --version

    You should see something like Python 3.12.x — the exact number doesn't matter.

macOS Instructions

  1. 1

    Open your web browser and go to python.org/downloads. The site will automatically show the latest version for macOS.

  2. 2

    Click the large yellow "Download Python 3.x.x" button at the top of the page.

  3. 3

    Open the downloaded .pkg file from your Downloads folder.

  4. 4

    Follow the installer steps — click Continue, Agree to the license, then Install. macOS may ask for your password — this is normal.

  5. 5

    When installation finishes, click Close.

  6. 6

    Verify it works: Open Terminal by pressing Cmd+Space, typing "Terminal", and pressing Enter. Then type the following command and press Enter:

    python3 --version

    You should see something like Python 3.12.x — the exact number doesn't matter.

Section 2: Install Required Python Packages

Python by itself is like a bare-bones workshop. Packages are free add-ons that give Python extra abilities — in this case, the ability to do advanced mathematics and draw graphs. You need to install two packages:

NumPy

Handles the complex mathematical calculations the simulations rely on

Matplotlib

Draws the graphs and plots you'll see when you run the programs

Windows Instructions

  1. 1

    Open Command Prompt (open the Start menu, search for "Command Prompt", and click it).

  2. 2

    Type (or copy-paste) the following command and press Enter:

    pip install numpy matplotlib
  3. 3

    You'll see text scrolling by — this is normal. Wait until you see "Successfully installed" messages. This may take a minute or two.

  4. 4

    That's it — the packages are now installed!

macOS Instructions

  1. 1

    Open Terminal (press Cmd+Space, type "Terminal", press Enter).

  2. 2

    Type (or copy-paste) the following command and press Enter:

    pip3 install numpy matplotlib
  3. 3

    You'll see text scrolling by — this is normal. Wait until you see "Successfully installed" messages. This may take a minute or two.

  4. 4

    That's it — the packages are now installed!

🔧

Troubleshooting

If you see an error saying "pip is not recognized" (Windows) or "command not found: pip3" (macOS), try restarting your computer and opening a new Command Prompt / Terminal window. This usually fixes the problem.

Section 3: Install PyCharm Community Edition

PyCharm is a free application designed specifically for working with Python programs. It gives you a comfortable environment to open, read, and run the GFTGU programs without needing to learn command-line tools. Think of it as a word processor, but for code.

Windows Instructions

  1. 1

    Open your web browser and go to jetbrains.com/pycharm/download/

  2. 2

    Scroll down to find "PyCharm Community Edition". Make sure it says Community (the free version), not "Professional".

  3. 3

    Click the "Download" button under Community.

  4. 4

    Run the downloaded .exe installer.

  5. 5

    Follow the setup wizard: click Next, accept defaults, check "Add 'Open Folder as Project'" on the Installation Options screen, click Next, then Install.

  6. 6

    When finished, click Finish (you can choose to restart now or later).

  7. 7

    Launch PyCharm from the Start menu.

macOS Instructions

  1. 1

    Open your web browser and go to jetbrains.com/pycharm/download/

  2. 2

    Scroll down to find "PyCharm Community Edition". Make sure it says Community (the free version), not "Professional".

  3. 3

    Click the "Download" button under Community — choose the .dmg appropriate for your Mac. If you have an M1, M2, M3, or M4 Mac, choose Apple Silicon. For older Macs, choose Intel. (If you're not sure, Apple Silicon is likely correct for any Mac purchased since late 2020.)

  4. 4

    Open the downloaded .dmg file.

  5. 5

    Drag the PyCharm icon into the Applications folder.

  6. 6

    Open PyCharm from your Applications folder or Launchpad.

  7. 7

    macOS may warn "PyCharm is from the internet" — click Open.

ℹ️

First launch

PyCharm may ask you to choose a UI theme (Light or Dark) and import settings. Choose whichever theme you like — it doesn't affect how programs run. Click "Don't import settings" if asked.

Section 6: Set Up the Python Interpreter in PyCharm

This is a one-time setup. PyCharm needs to know which Python installation to use. Think of it as introducing PyCharm to the Python engine you installed in Step 1.

  1. 1

    In PyCharm, go to File → Settings (or press Ctrl+Alt+S).

  2. 2

    In the left panel, click "Project: [folder name]" → "Python Interpreter".

  3. 3

    Click the gear icon ⚙ at the top right → "Add Interpreter" → "Add Local Interpreter…"

  4. 4

    Choose "System Interpreter" on the left.

  5. 5

    PyCharm should automatically find your Python installation. If you see a path ending in "python.exe", that's correct.

  6. 6

    Click OK, then OK again.

  1. 1

  2. 2

Section 7: Run a Program

  1. 1

    In PyCharm's Project panel (the left side), find the .py file (for example, "EarthOrbit.py").

  2. 2

    Double-click it to open it in the editor — you'll see the program code displayed. You don't need to understand the code; you just need to run it.

  3. 3

    To run the program, do either of these:
    Option A: Click the green ▶ Play button in the top-right toolbar.
    Option B: Right-click the .py file in the Project panel and choose "Run 'EarthOrbit'".

  4. 4

    A panel will open at the bottom of PyCharm — this is the "Run" panel where the program's output appears.

  5. 5

    Many programs will open a separate graph window showing the simulation results — this is normal and expected!

  6. 6

    To stop a program: click the red ■ Stop button in the Run panel.

✅

🎉 Success!

If a graph window pops up — congratulations! The program is running successfully. You're now exploring physics simulations from Gravity From the Ground Up.

🔧

Troubleshooting

If you see an error in red text in the Run panel mentioning "ModuleNotFoundError: No module named 'numpy'" (or matplotlib), that means the packages weren't installed correctly. Go back to Section 2 and follow those steps again. Make sure you're using the same Python installation that PyCharm is configured to use.

Section 10: Restoring a Program to Its Default Settings

When experimenting with the programs, you will inevitably change parameter values in main.py that you want to undo. Here are four methods, listed from quickest to most thorough — use whichever suits your situation.

1

Undo in PyCharm (same session only)

✓ Quickest

Works only if you have not closed PyCharm since making the change.

  • In PyCharm, press Ctrl+Z (Windows) or Cmd+Z (macOS) repeatedly to step back through your edits.

  • You can undo all the way back to the original file state.

  • Limitation: Undo history is lost when PyCharm closes. This method does not work across sessions.

2

PyCharm Local History

⭐ Recommended

PyCharm automatically saves a private history of every file you edit — no setup required. This works even after closing and reopening PyCharm.

  1. 1

    In the Project panel (left side of PyCharm), right-click the file you changed (e.g., main.py).

  2. 2

    In the menu that appears, choose Local History → Show History.

  3. 3

    A panel opens showing a timeline of every version PyCharm has saved.

  4. 4

    Click on an entry from before you made your changes — the old content appears on the right.

  5. 5

    Click Revert to restore that version.

💡

Local History is PyCharm's built-in time machine. It keeps versions for several days automatically and is the easiest restore method for most users.

3

Keep a backup copy before experimenting

🛡 Most reliable

A proactive habit: before changing any parameters for a new experiment, make a copy of main.py first.

  1. 1

    In the Project panel, right-click main.py.

  2. 2

    Choose Copy.

  3. 3

    Right-click the same folder and choose Paste — PyCharm will create main copy.py or similar.

  4. 4

    Rename it something meaningful, like main_defaults.py.

  5. 5

    Now you can freely edit main.py — your original is safe in main_defaults.py.

  6. 6

    To restore: open main_defaults.py, select all (Ctrl+A / Cmd+A), copy (Ctrl+C / Cmd+C), then open main.py, select all, and paste.

ℹ️

This is the most reliable long-term strategy. PyCharm Local History eventually expires; a backup copy lasts as long as you keep the file.

4

Re-download the ZIP from GitHub

🔄 Full reset

The nuclear option: always works, restores everything to factory defaults. Use this if multiple files have been changed or you want a completely fresh start.

Windows

  1. 1

    Go to github.com/tomyee3-org/GFTGU-Programs in your browser.

  2. 2

    Click the green "< > Code" button → "Download ZIP".

  3. 3

    Extract the ZIP to a new folder (e.g., GFTGU-Programs-fresh).

  4. 4

    Copy just the program folder you need (e.g., EarthOrbit) from the fresh download into your working location, replacing the modified version.

macOS

  1. 1

    Go to github.com/tomyee3-org/GFTGU-Programs in your browser.

  2. 2

    Click the green "< > Code" button → "Download ZIP".

  3. 3

    Double-click the ZIP to extract it to a new folder.

  4. 4

    Copy just the program folder you need from the fresh download into your working location, replacing the modified version.

⚠️

Re-downloading replaces all files in the folder. If you have any experiment notes or modified files you want to keep, save copies elsewhere first.
