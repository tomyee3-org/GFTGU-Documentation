Representative Sample Outputs

Version 1.13.0  |  Build da455c3a0668  |  Updated 8 October 2026

Purpose. One figure for each Beat of the Multiple Help, in Beat order, with a second figure for Beat 9's end-position window, for an instructor reading alongside the Help. Each section gives the exact command, the plot it produces, and the values the program prints. No external image files are required.

In the trajectory figures (1–3 and 5–7), each colored line is one body's path, in metres in the requested display frame, with equal axis scales. Figures 4 and 9 show the fractional total-energy drift (E−E0)/|E0| against simulated time. Figure 8 is one animation frame. Figures 10 and 11 show test particles in astronomical units, with angles measured from Jupiter.

Figure 1 — Beat 0 · Many bodies, one force law

python main.py --max_steps 8000 --output_type trajectories --n_bodies 3 --masses_solar 1,1,1 \
  --positions_init "46000000000,0,0;-46000000000,0,0;0,46000000000,0" \
  --velocities_init "0,0,0;0,-30000,0;-30000,0,0" --dt 2000 --eps1 0.005 --eps2 1e-07 --display_frame com

Three equal-mass stars start at the corners of a right triangle, two of them moving at 30 km/s; in the centre-of-mass (COM) display they fall together and two of them pass very close late in the run.

What it shows

  • Three trajectories (Body 1 red, Body 2 green, Body 3 blue) curve increasingly as gravity pulls all three together.
  • The plot subtracts the instantaneous centre of mass for display only; the printed totals use the input coordinates.
  • Near the end of the run two bodies swing very close to each other: the encounter that Beats 3, 6 and 8 return to.

Notes for evaluation

  • Display frames: display_frame='com' (the default; every trajectory figure except Figure 3) subtracts the instantaneous centre of mass for display only; 'user' (Figure 3) plots the input coordinates. Neither changes the printed E, P or L.
  • Conservation drift is a fraction of a characteristic scale, not of the literal initial value, only when the total cancels to within rounding error (Figure 5's exactly-zero momentum); a small but resolvable total, such as Beat 4's −25759 m/s variant, is used as its own scale.
  • Integrator: an adaptive predictor–corrector. The default close encounter collapses the working step by four orders of magnitude and recovers it by 10% per accepted step afterward; this is expected, not a defect.
  • Precision: printed totals use five significant digits; the mid-run drift can be larger than the last printed digit of the initial and final totals, as in Figure 4.
  • Animation: Figure 8 is one still frame; running the command plays all 31 frames, with Space/Left/Right/Home/End/F keyboard controls.
  • Test particles: Figures 10 and 11 come from --output_type survival runs, which store no paths. Closing the first window opens the second. The tadpole, horseshoe and circulating names describe the run made; a longer run can change them, as the tripled Trojan search shows for the horseshoes.

Image and source provenance

All eleven figures were regenerated for this guide from Multiple version 1.13.0, build da455c3a0668, on 8 October 2026; no earlier images were reused. Each was produced by running the command shown with Matplotlib's non-interactive Agg backend and saving each window the program would otherwise display (100 dpi). Figure 8's animation was moved to its final frame with an “end” key event before saving. Figure 4 is the second window of its run (after the trajectory plot), Figure 9 likewise, and Figure 11 is the second window of the Trojan search. The headline values are the console output of the same runs and of the other Beat commands named in them; the Beat 6 step sizes, the Beat 4 drift scales, the Beat 8 matched-window drifts and the Figure 11 ending ranges were read from the same runs' result data.
