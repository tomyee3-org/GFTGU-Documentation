RelativisticOrbit 1.1.0 Release Notes

Version: 1.1.0
Build: f2585119b36b
Date: 2026-09-16

Changes

  • All eight integration inputs and both plot switches can be set with python main.py --name value. --model schwarzschild selects the timelike Schwarzschild geodesic and --model newtonian the matched Newtonian comparison. --help lists descriptions and defaults.
  • The Help now gives runnable commands for every suggested exercise and identifies studies that also need a script or analysis of the returned arrays. The existing defaults still produce the same strong-field example.
  • The Sample Outputs guide includes newly generated figures and console summaries for the default rosette, matched Newtonian orbit, circular case, and horizon plunge.
  • Version and reproducible Build IDs identify the four core source modules across runtime output and documentation.

Scope

These are test-particle orbits around a fixed one-solar-mass central source. The Schwarzschild x-y curve is an areal-radius/azimuth diagram, and its proper-time derivatives are not locally measured speeds. Weak-field periapsis advances may be smaller than the numerical resolution of the supplied teaching integrator.
