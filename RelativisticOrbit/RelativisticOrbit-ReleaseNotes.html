Major Improvements in This Release

Version 1.4.0 (Audit 22 response, and a Help correction after Audit 23):

  • The Beats Help now says that the circular dy/dtau line is rounded to six significant figures and that a circular start needs the full value (Codex Audit 23 item 1); Experiment 6 prints each radius and circular speed in full. The program and its build are unchanged.
  • A start is predicted to be circular only when --u_init is within a few units in its last digit of the circular speed; any larger change of speed now gets its true prediction (for example plunge or bound), and circles close to, but not at, 6GM/c2 are no longer called the ISCO.
  • circular_proper_time_speed() is accurate to rounding close to 3GM/c2.
  • The Beat 4 command and Exercise 5 of RelativisticOrbit-original.html use the full circular speed 134071263.04595919; the former 14-digit value 134071263.04595 now prints motion : bound instead of circular (stable).
  • New public constants CIRCULAR_ULPS (8) and ISCO_ULPS (4) replace CIRCULAR_TOLERANCE and ISCO_TOLERANCE of 1.3.0.

Version 1.3.0 (Audit 21 response):

  • A start exactly on the ISCO circle prints motion : circular (marginally stable), with no advance line; it previously printed plunge.
  • weak_field_advance() gives finite values for very large radii (it returned 0 or NaN), and a turning point too large to represent prints motion : not predicted (...) instead of stopping with a traceback.

Version 1.2.0 (Kickoff2, not released separately):

  • Every run prints a periapsis radius line and a block predicted from the constants of motion: the circular dy/dtau at the starting radius, the kind of orbit with its turning points, the exact apsidal advance and the weak-field value 6πGM/(c2p). The previously printed lines are unchanged.
  • New public function predict_orbit(); result objects are frozen, with tuples in place of lists; the parser is available as build_parser().
  • New Beats tutorial Help, RelativisticOrbit-claude.html, with nine beats and 12 experiments; the Reference Guide Help is retained, kept current, as RelativisticOrbit-original.html. Its Exercise 7 now gives the periapsis as about 7565 m (7476 m at the default step), and both Exercise 10 commands use --max_steps 20000 so that the Newtonian control prints an advance.

Test Suite Growth

  • 1.1.1: 67 tests. 1.2.0: 131. 1.3.0: 139. 1.4.0: 144 (143 at the Audit 22 response, plus one check of the Help correction).
  • Run from the program folder with python -m unittest discover -s tests. In the full repository layout all 144 tests run and pass with no skips, in 15 to 20 seconds, on Python 3.11 and on Python 3.10.20. In a flat folder that holds only the program, the tests and the two Help files, the relative-link test is skipped (1 skip). Without RelativisticOrbit-original.html its 4 tests are skipped, and without SciPy the oracle-regeneration test is skipped.
  • New coverage since 1.1.1 includes predict_orbit() against an independent quadrature and the stored DOP853 oracle, the ISCO and other kind boundaries, regeneration of the DOP853 oracle, every command in the Beats Help, every number the Beats quote, and end-to-end runs.

Known Limitations

  • A single test particle around a fixed, non-rotating mass of one solar mass; no spin, radiation reaction or back-reaction.
  • The x-y plot draws areal radius and angle as flat polar coordinates; --u_init is a proper-time rate, not a measured speed.
  • The measured apsidal advance comes from periapsides at accepted steps; a Mercury-scale advance can be predicted but not measured.
  • Close to the hole the default step is coarse; near the plunge boundary the integrated fate can differ from the prediction (--u_init 1.045e8 crosses the horizon at the default settings).
  • There is no escape detector; an escaping run stops at --max_steps.
  • The turn count can overshoot --max_orbits by a fraction of one step.
  • The horizon end point is linearly interpolated and is left out of the drift maxima.
  • predict_orbit() treats a start within 8 units in the last digit of the circular speed as circular, and a circle within 4 units in the last digit of 6GM/c2 as the ISCO.
  • The equations in the Help are typeset by MathJax and need an internet connection.

Known Minor Maintenance Items

  • MathJax is not bundled for offline use.
  • The build identifier reads unpackaged when the physics module is loaded without the other core files.
  • RelativisticOrbit-original.html and RelativisticOrbit-claude.html are both present, and neither is marked as the current Help.
  • There is no option to save a figure or the orbit data to a file.
  • The DOP853 oracle can be regenerated only where SciPy is installed.
