RelativisticOrbit

Representative Sample Outputs

Version 1.4.0  |  Build 991fa89ab9b7  |  Updated 24 September 2026

Purpose. This compact, self-contained guide is for an instructor who has the RelativisticOrbit Help (RelativisticOrbit-claude.html) open. It shows one figure for each Beat of the Help, made with a command from that Beat, together with the values the run prints. It is not a retelling of the tutorial. No external image files are required.

RelativisticOrbit integrates the orbit of a test particle around a non-rotating black hole of one solar mass, in the particle's proper time, with a Newtonian comparison model. Every run prints a summary, including the orbit predicted exactly from the constants of motion, and then opens its plot. The program has no random numbers, so every command below reproduces the figure and numbers shown.

Contents

Beat 0 — The rosette

python main.py

The default particle, started 15000 m from a one-solar-mass black hole moving sideways, traces a rosette whose loops rotate from one pass to the next.

What it shows

  • The closest approach stays at the same distance, but each loop is rotated from the one before, so the orbit never closes.
  • The run stops at its 6000-step safety limit before it completes ten turns.
  • The horizon and the ISCO are drawn at their true radii, well inside the orbit.

Headline values

  • Termination: maximum accepted-step count reached; 6000 steps, proper time 0.012 s.
  • Azimuthal turns 9.285146; periapsides found 6, periapsis radius min 14999.8 m, max 15000 m.
  • Measured mean advance 2.44005 rad per radial period; predicted 2.44037 rad = 139.823 deg.
  • Predicted motion: bound, periapsis 15000 m, apoapsis 23954.4 m.

Beat 1 — Relativity switched off

python main.py --model newtonian

The same start under Newtonian gravity: an ellipse that closes on itself and reaches much farther out.

What it shows

  • Without the relativistic term the orbit closes: successive periapsides are at the same angle.
  • The Newtonian orbit swings out almost three times as far as the relativistic one.
  • In the same 6000 steps the particle completes far fewer turns, because it spends most of its time far out.

Headline values

  • Predicted motion: bound, periapsis 15000 m, apoapsis 65554 m; predicted advance 0 rad = 0 deg.
  • Azimuthal turns 2.572195; periapsides found 2.
  • Measured mean advance 0.00101314 rad, a numerical residue (relativistic run: 2.44005 rad).
  • Circular dy/dtau at 15000 m: 9.40611e+07 m/s (Schwarzschild: 1.12051e+08 m/s).

Beat 2 — The advance, predicted exactly

python main.py --u_init 1.1e8 --dt 5e-7 --max_steps 24000

A start slower than the circular value makes 15000 m the apoapsis; the predicted turning points and advance are checked against the integration.

What it shows

  • The start is now the farthest point of the orbit, because it is slower than the circular value.
  • The measured periapsis radius and advance agree with the prediction from the constants of motion.
  • The orbit that comes closer to the hole advances more per radial period than the default one.

Headline values

  • Predicted motion: bound, periapsis 13171.1 m, apoapsis 15000 m.
  • Periapsis radius found: min 13170.9 m, max 13170.9 m.
  • Measured advance 4.07277 rad; predicted 4.07222 rad = 233.321 deg.
  • Default orbit (Beat 0): predicted 2.44037 rad = 139.823 deg.

Beat 3 — The weak field

python main.py --x_init 1e6 --u_init 1.153e7 --dt 1e-4 --max_steps 20000

Far from the hole the orbit is almost a circle and the advance is under two degrees per radial period.

What it shows

  • The advance is small, and the weak-field formula now agrees with the exact prediction to better than 1%.
  • The measured advance matches the exact prediction to about 0.1%.
  • The Newtonian control from the same start measures a small non-zero advance, which shows the size of the numerical error.

Headline values

  • Predicted advance 0.0280972 rad = 1.60985 deg; weak-field 0.0279099 rad = 1.59912 deg.
  • Measured advance 0.0280654 rad; periapsis radius min 994558 m, max 994558 m.
  • Newtonian control (--model newtonian, same inputs): measured 0.000315267 rad, predicted 0 rad = 0 deg.
  • Energy drift 1.977e-08.

Beat 4 — Circular orbits and the ISCO

python main.py --x_init 7383.12519025 --u_init 212197265.2804 --dt 1e-7 --max_orbits 12 --max_steps 40000

A start 0.1% faster than circular at 5GM/c², inside the ISCO: the particle whirls near its starting radius, then swings out to twice that distance and back.

What it shows

  • An unstable circular orbit is left behind by a tiny push; here the particle is thrown out to twice its starting radius.
  • Each radial period contains almost five turns close to the hole.
  • The stable circle at 8GM/c², in the other command of this Beat, stays on its radius.

Headline values

  • Circular dy/dtau at 7383.1 m: 2.11985e+08 m/s; predicted motion: bound, periapsis 7383.13 m, apoapsis 15002.2 m.
  • Predicted advance 24.4301 rad = 1399.74 deg; measured 24.4374 rad.
  • Azimuthal turns 11.833533; periapsides found 2.
  • 8GM/c² circle: circular (stable), periapsis 11813 m, apoapsis 11813 m; predicted advance 6.28319 rad = 360 deg; energy drift 1.903e-08.

Beat 5 — Inside the ISCO, and back out

python main.py --x_init 20000 --u_init 8e7 --dt 2e-7 --eps1 0.01 --eps2 1e-6 --max_steps 20000

A particle that falls from 20000 m passes inside the ISCO and still comes back out, run with a small step and tight tolerances.

What it shows

  • The periapsis lies inside the ISCO, yet the orbit is bound and returns to 20000 m.
  • With tight settings the periapsis and advance match the prediction closely.
  • At the default settings, in the other command of this Beat, the orbit goes too deep and the advance is too large.

Headline values

  • Predicted motion: bound, periapsis 7564.95 m, apoapsis 20000 m; predicted advance 9.40306 rad = 538.756 deg.
  • Tight run: periapsis radius min 7564.13 m, max 7564.13 m, measured advance 9.40766 rad, energy drift 5.746e-05.
  • Default settings: periapsis radius min 7475.6 m, max 7476.56 m, measured advance 10.0873 rad, energy drift 4.988e-03.
  • ISCO radius 8859.8 m.

Beat 6 — The plunge

python main.py --u_init 1.044e8 --dt 1e-7 --eps1 0.005 --eps2 1e-6 --max_steps 12000

A start slightly too slow to stay bound: the particle whirls close to the hole and crosses the horizon.

What it shows

  • The constants of motion predict a plunge, and the run ends on the horizon.
  • Near the boundary between plunging and bound orbits the particle whirls several times before it falls in.
  • A start 0.1% faster is bound, but at the default settings its integrated orbit falls in anyway.

Headline values

  • Termination: Schwarzschild horizon crossed after 9266 steps and 2.844796 turns.
  • Predicted motion: plunge (no inner turning point; the orbit crosses the horizon).
  • --u_init 1.045e8, tight settings: bound, periapsis 7710.01 m, apoapsis 15000 m; measured advance 13.5564 rad against predicted 13.5506 rad = 776.393 deg.
  • --u_init 1.045e8, default settings: Schwarzschild horizon crossed after 3.932597 turns, energy drift 2.686e-02.

Beat 7 — How far to trust the orbit

python main.py --dt 2e-7 --eps1 0.01 --eps2 1e-6 --max_steps 60000

The default orbit of Beat 0 with one tenth of the step and tighter tolerances: the picture does not change, but the numbers improve.

What it shows

  • The drifts of the conserved quantities fall by about four each time the step is halved.
  • The measured advance approaches the prediction, but not steadily, because periapsides are found only at accepted steps.
  • The finest run agrees with the prediction to about 0.00004 rad.

Headline values

  • Energy drift: 1.573e-04 (dt 2e-6), 3.928e-05 (1e-6), 9.875e-06 (5e-7), 1.587e-06 (2e-7, tight).
  • Measured advance: 2.44005, 2.44109, 2.44014 and 2.44033 rad in the same order.
  • Predicted advance 2.44037 rad = 139.823 deg.

Beat 8 — Escape, Mercury and the hard cases

python main.py --u_init 1.8e8 --max_steps 12000

A start fast enough to escape: the particle curves once past the hole and leaves; the run simply stops when its steps run out.

What it shows

  • The program has no escape detector; the run ends at the step limit while the particle is still moving away.
  • The prediction names the orbit as an escape.
  • For Mercury's orbit the measured advance is numerical error far larger than the relativistic signal, in both models.

Headline values

  • Termination: maximum accepted-step count reached; azimuthal turns 0.394547; predicted motion: escape (no outer turning point).
  • Mercury (--x_init 4.6e10 --u_init 58980 --dt 1e4): predicted advance 5.01831e-07 rad = 2.87528e-05 deg.
  • Mercury measured advance: 0.000121605 rad (Schwarzschild), 0.000119678 rad (Newtonian).
  • python main.py --x_init 2000 is rejected: --x_init must lie outside the Schwarzschild horizon.

Notes for evaluation

  • Outside check: the lines under predicted from the constants of motion are exact for the equation the program integrates; the difference between a measured and a predicted advance is numerical error.
  • Numerical settings: close to the hole the default step is too coarse for quantitative work; Beats 5 to 7 compare default and tighter settings, and near the plunge boundary the default settings can give the wrong fate (Beat 6).
  • Measured advance: periapsides are found only at accepted steps, so the measured advance carries a sampling error as well as the integration error; a Mercury-scale advance cannot be measured, only predicted.
  • Scope: a single test particle in the equatorial plane of a non-rotating black hole; no spin, no radiation, no back-reaction. The plot draws areal radius and angle as if they were flat polar coordinates.
