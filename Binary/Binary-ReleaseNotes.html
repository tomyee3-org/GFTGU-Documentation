Major Improvements in This Release

  • Codex A42-P2-01. Grok Beat 1 now pins both signed acceleration components against accelerations() on a nonsymmetric state. Changing only the sign of x-acceleration of body B fails the complete suite.
  • Codex A42-P2-02. Every Grok python main.py command is taken from both pre blocks and inline code outside pre, parsed, and run. EXP-6 is a pre block. Changing only --MB 2e32 to --MB 0 fails the suite.
  • Claude A42-P3-01 / Codex A42-P3-02. EXP-6 now uses --uInitA 500000 (about 92 percent of circular speed around 2e32 kg at 4.6e10 m). Live check: elliptic, e about 0.147, about 218 steps and 5.05 days. The old 17000 m/s near-radial start is gone.
  • Claude A42-P3-02. Grok Help now has frozen display-equation and load-bearing-fragment pins (Newton, both acceleration signs, kinetic and boost energy, CM fraction, Kepler III a^3, hodograph, corrector-pass and step-growth wording, Beat 3 speeds).
  • Claude A42-P3-03. When a documentation tree is present (Notes, Guide, or GFTGU-Documentation/Binary), the suite fails unless dense Help (Binary-claude.html or Binary.html) is also present. Grok-only and no-Help layouts without that tree still skip.
  • Codex A42-P3-01. If the same Help filename exists both beside the program and under Documentation, the two copies must match byte for byte. A single copy in either place remains valid.

Test Suite Growth

255 automated tests in the Audit41 tree. This round adds Grok equation and fragment pins, inline-command extraction, a live EXP-6 check, a documentation-tree dense-Help guard, and a duplicate-copy byte check. Dense classes still skip in a Grok-only or no-Help layout that has no documentation tree. The full-tree gate is the complete discoverable suite with 0 skipped. The missing-Help precondition is a skip only when no documentation tree is in view; it is a failure when that tree is present.

Known Limitations

  • Educational Newtonian two-body model. No relativity, tides, finite size, collisions or third bodies.
  • A head-on start hits the timestep floor rather than an impact.
  • Highly eccentric orbits are inaccurate at the default eps1.
  • The one-revolution stop is a geometric angle rule, not a proof the path closed.
  • Some near-radial states at extreme scale (around 1e140 m) are rejected as out of range.
  • The printed energy table has eleven interpolated rows; (E−E0)/|E0| is poor when E0 is near zero.
  • There is no option to save the plot to a file.
  • Help loads MathJax from a public CDN; offline, equations appear as untypeset LaTeX.

Known Minor Maintenance Items

  • M-3. The "60 retries" error is reached in tests only by mocking the timestep floor.
  • M-4. The summary does not print the largest sampled energy departure or its time.
  • M-5. --help prints defaults such as 46000000000.0. plot_binary.py still lists a singular "orbit" output type the CLI never sends.
  • M-6. Dense phrase pins live on Binary-claude.html. Grok has short equation and fragment pins.
  • M-7. Repository-wide CI and lockfiles remain outside this module.
