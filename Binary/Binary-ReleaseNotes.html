Major Improvements in This Release

  • Audit41 / Codex A41-P2-02 (code). orbital_elements() returns kind radial, eccentricity 1, when h = 0, without forming r·v. Command: python main.py --MA 1e8 --MB 1e8 --xInitA 1e160 --xInitB 0 --vInitA 1e149 --vInitB 0 --uInitA 0 --uInitB 0 --dt 1e-3 --max_steps 2 --no-stop_after_one_orbit.
  • Codex A43-P2-01 / Claude A43-P3-01 / Codex A46-P3-01 / Claude A46-P3-01. EXP-6 is a zero centre-of-mass velocity start: A at 495049.50495 m/s, B at -4950.49505 m/s, relative speed 500000 m/s. Compare with a fixed 2e32 kg star at that same relative speed (about 5.11 days). Circular speed about that fixed mass is about 539000 m/s; 541000 m/s is the two-body relative circular speed. The centre of mass sits at x ≈ 4.55e8 m, not the origin. A matched Orbit command with --k 1.33486e22 and --vyInit 500000 is given. Initial K and E differ from the earlier parked-B start; accepted steps, period and e do not.
  • Codex A43-P2-02 / Codex A46-P2-01. Every distinct Binary command in the Grok Help is parsed and run. Exactly one data-program="Orbit" block is allowed, and only in EXP-6. A second marker, or a Beat 5 command that grows a --k flag, fails the suite.
  • Claude A43-P3-03. Grok pins now include the Parameters table against program defaults, Beat 0 start against the default run (e = 0.767), a live head-on timestep-floor check, exact display-equation blocks, and EXP-6 quoted numbers against the live run and the fixed-star Kepler period.

Known Limitations

  • Educational Newtonian two-body model. No relativity, tides, finite size, collisions or third bodies.
  • A head-on start hits the timestep floor rather than an impact.
  • Highly eccentric orbits are inaccurate at the default eps1.
  • The one-revolution stop is a geometric angle rule, not a proof the path closed.
  • Some near-radial states at extreme scale (around 1e140 m) are rejected as out of range.
  • The printed energy table has eleven interpolated rows; (E−E0)/|E0| is poor when E0 is near zero.
  • There is no option to save the plot to a file.
  • Help loads MathJax from a public CDN; offline, equations appear as untypeset LaTeX.

Known Minor Maintenance Items

  • M-3. The "60 retries" error is reached in tests only by mocking the timestep floor.
  • M-4. The summary does not print the largest sampled energy departure or its time.
  • M-5. --help prints defaults such as 46000000000.0. plot_binary.py still lists a singular "orbit" output type the CLI never sends.
  • M-6. Dense phrase pins live on Binary-extended.html. Grok has equation, table and fragment pins.
  • M-7. Repository-wide CI and lockfiles remain outside this module.

Version 1.3.0 — Centre-of-Mass Display (2026-10-01)

Version: 1.3.0
Build: 82f6206a5be0
Date: 2026-10-01

  • Added --frame user|com. The default user view retains the existing plots. The com view removes the sampled mass-weighted centre and velocity from orbit, position and velocity plots, and calculates kinetic and total energies in that frame. COM plot titles identify the frame.
  • The display choice does not change initial conditions, integration, termination, orbital diagnostics or the printed input-frame energy table. BinaryResult now carries the two input masses for plotting. Results created manually without those masses still support user-frame plots, but COM plots require finite positive masses.
  • Beat 2 in both current tutorials now compares translated and boosted input-frame plots with their COM views. The Sample Outputs Guide includes the boosted COM plot. A common boost preserves the exact relative motion, while the existing corrector's convergence decisions can introduce small frame-dependent numerical differences.
  • Added regression checks for unequal masses, translation and two-component boosts, all seven COM plot types, energy decomposition, unchanged saved results and summaries, CLI routing and rejected frame values.
  • Updated stale Help tests to accept the edited prose without requiring emphasized “Then”, and to find Experiment 6 by its existing anchor.

Validation: 277 tests run, 0 skipped, OK with MPLBACKEND=Agg python -W error::RuntimeWarning -m unittest discover -s tests; both current tutorials and the sample guide pass HTML parsing and MathJax delimiter checks; the COM orbit and energy plots were visually checked. The MINOR version increases because a new public CLI and plotting option was added. The integrator and default numerical results are unchanged.
