Binary 1.3.1 Release Notes

Version: 1.3.1
Build: 69499344c088
Date: 2026-10-07

Release Status

Minor maintenance update following the accepted 1.3.0 COM-frame round, which dates from 2 October 2026. The two most recent code-changing rounds are 1.3.0 (COM display selection) and 1.3.1 (explicit USER-frame plot titles). Grok and Claude both recommended ACCEPT for 1.3.0; those recommendations do not constitute an external review of 1.3.1. The earlier notes, including their 1 October preparation date and audit history, are preserved below.

Documentation changes are compared with GFTGU-Documentation(20261002-120516).zip. Program changes are compared with the latest source supplied in GFTGU-Binary Documentation and Program.zip. The display checks pass; the full supplied suite still has pre-existing checks tied to retired Help layouts, listed under maintenance items.

Open Bugs

No unresolved reviewer-reported P1–P3 program defects are recorded. The requested missing USER-frame title is corrected. The remaining test-maintenance discrepancy is stated below; the full suite is not represented as passing.

Major Improvements in This Release

  • Every plot title now identifies its selected USER frame or COM frame. This includes default runs, explicit --frame user runs, all seven CLI plot types and the existing singular orbit alias. The numerical solver, plotted data, frame transformations and diagnostic numbers are unchanged; the console version/build stamp advances to 1.3.1/69499344c088.
  • B1 is covered in Suggested Experiment 6 of the merged Binary.html: compare the Sun's reflex orbit and its radius for Sun–Jupiter, Sun–Saturn and Sun–Earth pairs in the COM frame, then distinguish those isolated pairs from the multi-planet problem in Multiple.
  • Since the 2 October short tutorial, the Help makes comparison defaults explicit, states that the two forces have equal magnitudes and opposite directions, defines the separation components, qualifies period agreement and full-turn overshoot, and presents Suggested Experiments as numbered cards. The supplied manual edits are retained.
  • The nine sample figures are regenerated from this build with the commands shown, using commands equivalent to those in the merged Help. USER-frame labels are visible, the COM comparison remains, and the supplied guide's malformed contents links are repaired. Headline diagnostic values remain unchanged.
  • Plot regression checks now require the USER label while retaining their exact data, axis-unit and legend checks. A new test covers explicit and default user views. The B1 investigation has a coverage check, and the Beat 2 frame-comparison check accepts explicit defaults while still requiring the same boosted initial state and all three frame/output combinations.

Test Suite Growth

265 tests before COM; 277 in the initial 1.3.0 package; 282 in the accepted COM package; 287 in the supplied merged-Help baseline; 289 in 1.3.1. Run from GFTGU-Programs/Binary with MPLBACKEND=Agg python -W error::RuntimeWarning -m unittest discover -s tests. The full 1.3.1 suite reports 193 passed, 18 pre-existing Help-check failures and 78 skips; all 39 focused display, frame, CLI, build and current-Help checks pass without skips. All 22 documented Binary runs retain identical diagnostic text apart from the version/build stamp. Historical passing results below apply to their original packages.

Known Limitations

  • Educational planar Newtonian point masses; no relativity, tides, finite sizes, collisions or third body. Isolated Sun–planet runs are not a Solar-System ephemeris.
  • Frame selection affects plots only; the summary and energy table use input-frame values. The corrector's input-frame speed comparison can make a common boost change convergence decisions slightly.
  • Highly eccentric orbits need convergence checks; head-on starts reach the timestep floor. One relative revolution is not proof of exact closure, and the stop can overshoot by an accepted step.
  • Some extreme-scale near-radial inputs are rejected. Energy rows are interpolated, and fractional departures are poorly conditioned near zero initial total energy.
  • No CLI figure-save option; Help MathJax uses a public CDN. The Sun's plotted reflex scale is to be compared with a physical radius even though the simulation treats the Sun as a point mass.

Known Minor Maintenance Items

  • M-6: The supplied suite has assertions for retired dense/extended Help layouts and wording. They fail or skip against the merged Binary.html; this update preserves those findings rather than changing the author's text to satisfy legacy pins. The current comparison report identifies each remaining failure.
  • M-3/M-4: The 60-retry branch is covered using a mocked floor; the summary does not print the largest sampled energy departure or its time.
  • M-5/M-7: Some CLI defaults print in long decimal form; the plotter retains its singular orbit alias; repository-wide CI and lockfiles remain outside this module.
  • Cross-program CLI naming, frame labels on plot axes and a frame line in the printed summary remain deferred. The previously deferred user-view title label is now implemented.

Major Improvements in This Release

  • --frame user|com selects the display frame for all seven plots. The default user view retains the input coordinates. The COM view uses mass-weighted relative positions and velocities and recalculates kinetic and total energies in that frame.
  • Beat 2 explicitly compares a 60000 m/s boosted run in the input-frame orbit view, COM orbit view and COM energy view. The restored ellipses each have a focus at the centre of mass, not their geometric centre. The short tutorial asks which energy classifies the internal orbit.
  • The energy and hodograph lessons distinguish printed input-frame values from COM plot values. A worked velocity-space comparison shows why the origin-inside-circle test requires velocities relative to the centre of mass.
  • Both tutorials define COM, its equivalence to the Newtonian centre-of-momentum frame, and the CM equation subscripts. Abbreviations in the short tutorial are expanded.
  • All nine sample figures are regenerated together from this core build. Beat 2 retains the input/COM comparison pair. Image count, provenance, figure descriptions and numerical-accuracy qualifications are corrected.
  • Regression tests preserve the order of the substantive tasks without requiring emphasized “Then”. Missing or reversed task sequences fail. Command checks include the COM energy and hodograph examples; focus wording, figure provenance and zero-momentum frame qualifications are checked.

Test Suite Growth

265 tests before the COM feature; 277 in the initial 1.3.0 COM package; 282 tests in this audited package, 0 skipped, OK. Command: MPLBACKEND=Agg python -W error::RuntimeWarning -m unittest discover -s tests. Both current tutorials and the sample guide pass HTML parsing and MathJax delimiter checks. The guide's nine live figures were visually checked after regeneration; Claude’s second audit independently reproduced all nine figures pixel for pixel.

Known Limitations

  • Educational Newtonian point-mass model; no relativity, tides, finite size, collisions or third bodies.
  • --frame com changes plots only. The printed summary and energy table stay in the input frame, so a boosted bound pair can print positive total energy while its COM energy plot shows negative internal energy. The plot title identifies the COM frame.
  • The corrector compares velocity changes with input-frame speeds, so a common boost can change convergence decisions and leave small differences in the integrated relative paths. Display-frame selection does not alter those decisions.
  • Highly eccentric orbits are inaccurate at the default eps1; check convergence with tighter settings. A head-on start hits the timestep floor rather than an impact. One relative revolution is not proof of exact path closure.
  • Some near-radial states at extreme scale (around 1e140 m) are rejected as out of range.
  • The eleven printed energy rows are interpolated; fractional departures are poorly conditioned when the starting total energy is near zero.
  • There is no CLI plot-save option. MathJax uses a public content delivery network; offline equations remain untypeset.

Known Minor Maintenance Items

  • M-3. The "60 retries" error is reached in tests only by mocking the timestep floor.
  • M-4. The summary does not print the largest sampled energy departure or its time.
  • M-5. --help prints defaults such as 46000000000.0. plot_binary.py still lists a singular "orbit" output type the CLI never sends.
  • M-6. Dense phrase pins live on Binary-extended.html; Binary-short.html has equation, table and fragment pins.
  • M-7. Repository-wide CI and lockfiles remain outside this module.

Cross-program CLI naming, explicit frame labels on plot axes and user-view titles, a frame line in the printed summary, and cosmetic differences between the short and extended tutorials remain deferred. Input-frame orbit plots with a large boost can appear as thin strips because the axes use equal physical scales; the guide explains the zoom option.
