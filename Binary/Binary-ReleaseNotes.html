Binary 1.3.0 Release Notes

Version: 1.3.0
Build: 82f6206a5be0
Date: 2026-10-01

Release Status

ACCEPTED for release. Grok’s Audit_COM_Frame2 dated 2026-10-01 and Claude’s Audit_COM_Frame2 dated 2026-10-02 both recommend ACCEPT, with no P1 or P2 findings. Final documentation corrections carry forward the known limitations and maintenance items and correct the Beat 6 figure description. The four executable modules are unchanged; MODEL_VERSION remains 1.3.0 and BUILD_ID remains 82f6206a5be0.

Open Bugs

None recorded for this release. The limitations and maintenance items below remain applicable.

Major Improvements in This Release

  • --frame user|com selects the display frame for all seven plots. The default user view retains the input coordinates. The COM view uses mass-weighted relative positions and velocities and recalculates kinetic and total energies in that frame.
  • Beat 2 explicitly compares a 60000 m/s boosted run in the input-frame orbit view, COM orbit view and COM energy view. The restored ellipses each have a focus at the centre of mass, not their geometric centre. The short tutorial asks which energy classifies the internal orbit.
  • The energy and hodograph lessons distinguish printed input-frame values from COM plot values. A worked velocity-space comparison shows why the origin-inside-circle test requires velocities relative to the centre of mass.
  • Both tutorials define COM, its equivalence to the Newtonian centre-of-momentum frame, and the CM equation subscripts. Abbreviations in the short tutorial are expanded.
  • All nine sample figures are regenerated together from this core build. Beat 2 retains the input/COM comparison pair. Image count, provenance, figure descriptions and numerical-accuracy qualifications are corrected.
  • Regression tests preserve the order of the substantive tasks without requiring emphasized “Then”. Missing or reversed task sequences fail. Command checks include the COM energy and hodograph examples; focus wording, figure provenance and zero-momentum frame qualifications are checked.

Test Suite Growth

265 tests before the COM feature; 277 in the initial 1.3.0 COM package; 282 tests in this audited package, 0 skipped, OK. Command: MPLBACKEND=Agg python -W error::RuntimeWarning -m unittest discover -s tests. Both current tutorials and the sample guide pass HTML parsing and MathJax delimiter checks. The guide's nine live figures were visually checked after regeneration; Claude’s second audit independently reproduced all nine figures pixel for pixel.

Known Limitations

  • Educational Newtonian point-mass model; no relativity, tides, finite size, collisions or third bodies.
  • --frame com changes plots only. The printed summary and energy table stay in the input frame, so a boosted bound pair can print positive total energy while its COM energy plot shows negative internal energy. The plot title identifies the COM frame.
  • The corrector compares velocity changes with input-frame speeds, so a common boost can change convergence decisions and leave small differences in the integrated relative paths. Display-frame selection does not alter those decisions.
  • Highly eccentric orbits are inaccurate at the default eps1; check convergence with tighter settings. A head-on start hits the timestep floor rather than an impact. One relative revolution is not proof of exact path closure.
  • Some near-radial states at extreme scale (around 1e140 m) are rejected as out of range.
  • The eleven printed energy rows are interpolated; fractional departures are poorly conditioned when the starting total energy is near zero.
  • There is no CLI plot-save option. MathJax uses a public content delivery network; offline equations remain untypeset.

Known Minor Maintenance Items

  • M-3. The "60 retries" error is reached in tests only by mocking the timestep floor.
  • M-4. The summary does not print the largest sampled energy departure or its time.
  • M-5. --help prints defaults such as 46000000000.0. plot_binary.py still lists a singular "orbit" output type the CLI never sends.
  • M-6. Dense phrase pins live on Binary-extended.html; Binary-short.html has equation, table and fragment pins.
  • M-7. Repository-wide CI and lockfiles remain outside this module.

Cross-program CLI naming, explicit frame labels on plot axes and user-view titles, a frame line in the printed summary, and cosmetic differences between the short and extended tutorials remain deferred. Input-frame orbit plots with a large boost can appear as thin strips because the axes use equal physical scales; the guide explains the zoom option.

Major Improvements in This Release

  • Audit41 / Codex A41-P2-02 (code). orbital_elements() returns kind radial, eccentricity 1, when h = 0, without forming r·v. Command: python main.py --MA 1e8 --MB 1e8 --xInitA 1e160 --xInitB 0 --vInitA 1e149 --vInitB 0 --uInitA 0 --uInitB 0 --dt 1e-3 --max_steps 2 --no-stop_after_one_orbit.
  • Codex A43-P2-01 / Claude A43-P3-01 / Codex A46-P3-01 / Claude A46-P3-01. EXP-6 is a zero centre-of-mass velocity start: A at 495049.50495 m/s, B at -4950.49505 m/s, relative speed 500000 m/s. Compare with a fixed 2e32 kg star at that same relative speed (about 5.11 days). Circular speed about that fixed mass is about 539000 m/s; 541000 m/s is the two-body relative circular speed. The centre of mass sits at x ≈ 4.55e8 m, not the origin. A matched Orbit command with --k 1.33486e22 and --vyInit 500000 is given. Initial K and E differ from the earlier parked-B start; accepted steps, period and e do not.
  • Codex A43-P2-02 / Codex A46-P2-01. Every distinct Binary command in the Grok Help is parsed and run. Exactly one data-program="Orbit" block is allowed, and only in EXP-6. A second marker, or a Beat 5 command that grows a --k flag, fails the suite.
  • Claude A43-P3-03. Grok pins now include the Parameters table against program defaults, Beat 0 start against the default run (e = 0.767), a live head-on timestep-floor check, exact display-equation blocks, and EXP-6 quoted numbers against the live run and the fixed-star Kepler period.
