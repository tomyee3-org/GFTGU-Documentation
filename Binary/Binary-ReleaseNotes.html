Release Status

Version 1.2.3 follows 1.2.2 by repairing the remaining orbital-elements range failures recorded as OB-1, softening two Beat 5 wording items (M-1, M-2) in both Beats Help files, and making the test suite treat Binary-claude.html and Binary-grok.html as dual Help that share the same core program, the same Sample Outputs Guide, and the same version and build stamps. Default-run numbers are unchanged from 1.2.2. These notes replace the 1.2.2 notes; the earlier notes are not reproduced.

Open Bugs

None recorded for this release. The 1.2.2 item OB-1 is closed below.

Major Improvements in This Release

  • OB-1 closed. orbital_elements() now classifies finite states whose intermediate products overflow or underflow, when the elements themselves are representable. The former hyperbolic example (python main.py --MA 7.49e106 --MB 7.49e106 --xInitA 5e149 --xInitB -5e149 --uInitA 5e99 --uInitB -5e99) prints a hyperbolic orbit of eccentricity about 1.0002×10253 instead of exiting after a successful integration. The same state with radial velocities prints kind radial and eccentricity 1. The tiny equal-mass needle ellipse orbital_elements(7.49e307, 7.49e307, 5e-11, 0, 0, 0.5, -5e-11, 0, 0, -0.5) returns an elliptic orbit of semi-major axis 5×10−11 m instead of raising ZeroDivisionError. The helpers are mantissa/exponent products already used for energy and acceleration; they do not change any previously printed default-run figure.
  • M-1, M-2. Beat 5 in both Help files now says the two-body conic is about the centre of mass, and that row 0.5 is the closest-approach sample on the apoapsis-start runs shown, not an identity for every possible start.
  • Dual Help. Binary-claude.html remains the dense lab-manual Beats file that the quoted-number and structure tests pin. Binary-grok.html remains the shorter terminal-script Beats file. Both carry Version 1.2.3 and build 7b64e2aa7973. The test suite discovers both, pins the dense contract on the Claude file, and checks that the Grok file has the same stamps, Beats 0–7, runnable commands, and the same licence line.

Test Suite Growth

239 → 248 automated tests. The suite is run once from tests/ with the Help, Release Notes and Sample Outputs Guide in the repository layout beside the modules. New coverage: the three OB-1 states (hyperbolic, radial, tiny elliptic), the former OB-1 command line after a one-step integration, discovery of both Beats Help files, matching version/build stamps in both files, and that every command shown in the Grok Help parses. No uploaded test was removed or loosened.

Known Limitations

  • Educational model of two Newtonian point masses acting only through mutual gravity, not an ephemeris or research orbital-dynamics code. No relativity, gravitational radiation, tides, rotation, finite size, collisions, mass transfer, external fields or third bodies.
  • Point-mass gravity is singular at zero separation: an unresolvable close approach, such as an inward radial start, ends in a numerical-safety error instead of an impact or a softened passage.
  • The Euler-predictor and iterated-trapezoidal-corrector method accumulates error; results should be repeated with smaller dt and stricter tolerances. An orbit far more eccentric than the default is inaccurate at the default eps1 (Experiment 8: a largest sampled energy departure of 25.9%).
  • The one-revolution stop follows the accumulated signed angle of the relative position; it can pass 2π by part of a step and does not prove the trajectory is closed. Radial and unbound runs normally continue to max_steps unless an error stops them earlier.
  • Invariance under a common velocity boost is approximate because the corrector test is applied to each body separately.
  • The printed energy table has eleven interpolated rows; the largest departure can fall between them. (E−E0)/|E0| is undefined or large when E0 is near zero.
  • Finite inputs whose derived displacement, acceleration or energy is outside the double-precision range are rejected rather than approximated. A needle ellipse whose periapsis underflows is reported with periapsis 0 and an undefined periapsis speed.
  • There is no option to save the plot to a file.
  • The Help files load MathJax from a public CDN; offline, equations appear as untypeset LaTeX.

Known Minor Maintenance Items

  • M-3 (Codex A22-P4-04, Grok N2). The “60 retries” error in driver_binary.py cannot be reached (the step floor stops the run on the 40th halving); its test reaches it only by replacing _halve_timestep() with a mock.
  • M-4 (Codex A21-P3-06, Grok N1). The summary does not print the largest sampled energy departure or its time; Experiment 8 supplies a script instead.
  • M-5. --help prints floating-point defaults such as 46000000000.0. In physics_binary.py the min(e, 1) cap in the bound branch now does act on a needle ellipse whose computed eccentricity rounds above 1. plot_binary.py still lists a singular “orbit” output type that the command line never sends.
  • M-6. Help wording tests pin exact phrases on Binary-claude.html, so rewording a pinned sentence means editing its test. The Grok Help is checked for stamps, Beats and commands, not for those dense phrases.
  • M-7. Repository-wide continuous integration and dependency-lock policy remain outside this module; the extreme-value tests should stay focused rather than gain a test for every equivalent permutation.
