Release Status

Version 1.2.4 answers Audit41 of Kickoff4 (1.2.3 / 7b64e2aa7973). Codex recommended HOLD on two P2s (Grok Help untested for its governing law; a finite radial state still aborted after a successful integration). Claude recommended HOLD on P3 documentation only and treated OB-1 as closed. This release closes both Codex P2s and the shared EXP-4 / Grok-pin / layout P3s. Default-run numbers are unchanged. These notes replace the 1.2.3 notes.

Open Bugs

None recorded for this release.

Major Improvements in This Release

  • Codex A41-P2-02. orbital_elements() classifies an exactly radial state before it forms the radial product r·v. The finite case python main.py --MA 1e8 --MB 1e8 --xInitA 1e160 --xInitB 0 --vInitA 1e149 --vInitB 0 --uInitA 0 --uInitB 0 --dt 1e-3 --max_steps 2 --no-stop_after_one_orbit now prints kind radial, eccentricity 1, instead of exiting after two accepted steps.
  • Codex A41-P2-01, Claude A41-P3-02. The shared suite now pins Grok Beat 0 to Newton's inverse-square law, the hodograph formula, the relative escape speed in EXP-4, and the 10 per cent step-growth wording. Changing Grok Beat 0 from r^2 to r^3 fails the complete suite.
  • Claude A41-P3-01 / Codex A41-P3-01. Grok EXP-4 now asks for \(\sqrt{2G(M_A+M_B)/r}\) and half of that for equal CM speeds. The old "reduced mass" square root is gone.
  • Claude A41-P3-05. Dense Help tests skip when only Grok is present. Discovery never treats Grok as the canonical file. Physics tests import with no Help file.

Test Suite Growth

248 → 255 automated tests. Added: overflowing-r·v radial elements and CLI summary; Grok inverse-square, hodograph, EXP-4 and EXP-6 pins. Dense classes skip in a Grok-only or no-Help layout instead of failing at import. No uploaded test was removed or loosened.

Known Limitations

  • Educational Newtonian two-body model. No relativity, tides, finite size, collisions or third bodies.
  • A head-on start hits the timestep floor rather than an impact.
  • Highly eccentric orbits are inaccurate at the default eps1.
  • The one-revolution stop is a geometric angle rule, not a proof the path closed.
  • Near-radial states whose r·v overflows a double, while h is a tiny nonzero value, are still rejected as out of range.
  • The printed energy table has eleven interpolated rows; (E−E0)/|E0| is poor when E0 is near zero.
  • There is no option to save the plot to a file.
  • Help loads MathJax from a public CDN; offline, equations appear as untypeset LaTeX.

Known Minor Maintenance Items

  • M-3. The "60 retries" error is reached in tests only by mocking the timestep floor.
  • M-4. The summary does not print the largest sampled energy departure or its time.
  • M-5. --help prints defaults such as 46000000000.0. plot_binary.py still lists a singular "orbit" output type the CLI never sends.
  • M-6. Dense phrase pins live on Binary-claude.html. Grok now has its own short fact pins.
  • M-7. Repository-wide CI and lockfiles remain outside this module.
  • P4-02 carried. Some near-radial extreme-range states still raise a range error; see Known Limitations.
