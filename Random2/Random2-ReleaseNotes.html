Release Status

These notes cover Version 1.4.0 and the two code-changing rounds that produced it: the Kickoff2 conversion (1.3.0) and the Audit 21 response (1.4.0). The Audit 22 response changed only the two Help files and the tests; Audit 23 changed nothing and only reviewed 1.4.0. Version 1.3.0 was never released separately; the last published notes were for 1.2.0.

  • Grok, Audit 23: freeze both Help files; no new defect. No hold.
  • Codex, Audit 23: one P2 in the Reference Guide Help, Random2-original.html (OB-1); no other recommendation. No hold stated.

Open Bugs

  • OB-1 (P2; Codex Audit 23 item 1). Random2-original.html states the square-root law of Eq. (6) as exact for every step count and says that more trials bring the measured trend to slope 1/2; the mean scaled distance follows the law only for large step counts.
    Reproduction: python main.py --max_steps 2 --n_trials 200000 --seed 12. Observed: mean scaled distance 1.3844 (standard error 0.0010), ratio to sqrt(N) 0.9789, against the large-N prediction 0.9591, while Eq. Major Improvements in This Release

Version 1.4.0 (Audit 21 response):

  • A radius whose ratio to the mean free path lies outside 1e-150 to 1e150 is rejected with an input/model error; it previously stopped with a Python traceback (1e155) or printed inf (1e-160).
  • With --radius given, the star annotation shows (given) after the radius and no longer shows the unused reference step count.
  • Lengths in the summary and the annotation no longer print as 0.00 for very small stars.
  • Help corrections: Experiment 9 uses (R/λ)2 and its correct bound; the square-root law of Beat 0 is marked as a large-N result. The Audit 22 response then corrected a typeset error in Eq. (5) and the seed wording, without changing the program.

Version 1.3.0 (Kickoff2):

  • New option --seed makes a run repeatable; without it every run differs, as before.
  • Every run now prints a summary before its plot: for scaled_distance, a table of mean scaled distance, standard error and ratio to sqrt(N), the large-N prediction for that ratio and the fitted log-log slope; for walk2d, R, (R / mean free path)^2, each walk's escape step count (up to 12 walks) and the escape statistics.
  • The scaling plot shows the fitted slope; the star plot's median is printed to one decimal, and its frame leaves room for long rays.
  • --max_steps below 2 is rejected by the command-line parser.
  • Result objects are immutable, and the driver adds run_scaled_distance_statistics() and escape_statistics(); run_scaled_distance_experiment() still returns two lists.
  • New Beats tutorial Help, Random2-claude.html, with nine beats and 11 experiments; the Reference Guide Help is retained, kept current, as Random2-original.html.

Test Suite Growth

  • 1.2.0: 59 tests. 1.3.0: 123. 1.4.0: 146 (133 in the Audit 21 response, 137 in the Audit 22 response, plus nine checks of these two documents).
  • Run from the program folder with python -m unittest discover -s tests. In the full repository layout all 146 tests run and pass with no skips, in about 40 seconds. In a flat folder that holds only the program, the tests and Random2-claude.html, the link check, the Random2-original.html tests and these document checks are skipped (13 skips), and the rest pass.
  • New coverage since 1.2.0 includes every command shown in the Help, every number the Help and the Sample Outputs Guide quote, the equation tags and index, the seed option, the printed summaries, the input limits, and end-to-end runs of both displays.

Known Limitations

  • An educational model of random walks; no solar opacity profile, changing mean free path or convection zone.
  • The star display is two-dimensional; its escape-time distribution is not that of a three-dimensional star.
  • The uniform-component steps fill a cube and are not isotropic in direction.
  • Results vary from run to run unless --seed is given.
  • Walks stopped by --step_cap are left out of the escape statistics, which then understate the mean.
  • The ratio of radius to mean free path must lie between 1e-150 and 1e150.
  • The equations in the Help are typeset by MathJax and need an internet connection.

Known Minor Maintenance Items

  • The build identifier reads unknown, rather than stopping with an error, if a core file cannot be read.
  • The result dataclasses live in random2_driver.py, not in a separate neutral module.
  • The statistical test tolerances assume Python's current random-number algorithms.
  • Random2-original.html and Random2-claude.html are both present, and neither is marked as the current Help.
  • The Related Programs links point to Star.html and to the current Neutron Help file names.
  • There is no option to save a figure or the escape step counts to a file.
