Major Improvements in This Release

  • 1.3.0: coarse-step Earth-crossing check. A single step whose straight-line path passes through Earth, with both ends outside it, now stops the run with a one-line command-line error. Before, the run was reported as an orbit or an escape. Example: python main.py --h0 300000 --uInit 0 --vInit -20000 --dt 1000 --maxSteps 2 --force_law inverse_square now prints EarthOrbit: this step's straight-line displacement passed through Earth's reference surface ....
  • 1.3.0: rounding at a power of ten. Printed values keep exactly five significant digits when rounding carries into the next power of ten. For example, 99999.9 now prints as 1.0000e+05 instead of 100000. This changes printed numbers only at such boundaries; the default run's output is unchanged.
  • 1.4.0: Earth-crossing check at extreme values. The check no longer fails for extremely large but finite single-step displacements. Example: python main.py --h0 300000 --uInit 0 --vInit=-1e155 --dt 1 --maxSteps 2 --force_law inverse_square now stops with the Earth-crossing error instead of reporting an escape.
  • Help. The new tutorial Help file, EarthOrbit-claude.html, is organised as numbered Beats (0 to 9) with runnable commands and printed values checked against this build. The classic EarthOrbit.html now describes the Earth-crossing error as a third way a run can stop.

Test Suite Growth

  • 1.2.0 as released: 79 tests. After Kickoff2 (no code change): 80.
  • 1.3.0: 83 tests, adding checks for the coarse-step Earth-crossing error, for ordinary runs not triggering it, and for rounding at a power of ten.
  • 1.4.0: 87 tests, adding direct geometric tests of the Earth-crossing check, a test with extreme input values, and a verified near-miss orbit with a +200 m ideal perigee.

The sibling GFTGU-Documentation/EarthOrbit/ folder must hold EarthOrbit.html, EarthOrbit-claude.html, these notes, and SampleOutputs/EarthOrbit-SampleOutputs_Guide.html. With this documentation set, 87 of 87 pass.

Known Limitations

  • The default simplified law keeps the acceleration at the textbook 9.8 m/s² at every altitude. It is a near-surface teaching model, not a global model of gravity.
  • inverse_square treats Earth as a point mass with the JPL DE440 value MU_EARTH = 3.98600435507e14 m³/s² and the textbook reference radius R_EARTH = 6,378,200 m.
  • The simulation is two-dimensional. It has no atmosphere, drag, Earth rotation, oblateness, third-body forces or station-keeping.
  • The fixed-step integrator is first-order and not symplectic, and results drift with dt. For example, the 300 km circular orbit reaches 348.47 km at dt = 1 s.
  • The printed osculating elements describe the ideal two-body orbit implied by the launch state, not the computed trajectory.
  • Near the ground, whether a run reports impact or orbit depends on dt. At coarse dt, some launch speeds stop with the Earth-crossing error instead.
  • The Earth-crossing check tests the straight line between stored samples. It can stop a run whose curved path would have stayed above the surface.
  • Impact points and revolution boundaries use linear interpolation, and altitude extrema use a three-point parabola. Both approach the true values as dt shrinks but are not exact.
  • Angular travel is counted as never decreasing, so a trajectory that reverses direction around Earth is not shown unwinding.
  • After an impact, the plotted curve keeps the first stored sample below the surface; the printed values stop at the interpolated crossing.
  • Printing five significant digits does not mean the model or method is that accurate.
  • maxSteps counts stored points including the launch point, so a run makes at most maxSteps − 1 steps.
  • The plot always opens in an interactive window. There is no option to save it to a file.
  • Both Help files load MathJax from a public CDN. Offline, equations appear as raw TeX.

Known Minor Maintenance Items

  • The console's Osculating ... lines do not say the elements are "at launch" (Grok Audit21 P1).
  • The Escape trajectory outcome describes the launch state as unbound; the console does not say "at launch" (Grok Audit21 P2).
  • The Help-file tests read the classic EarthOrbit.html, not EarthOrbit-claude.html. Which file should be the test reference is undecided (Grok Audit21 P6).
  • Whether students get the long Beats Help or a shorter version is undecided.
  • The classic Help says the launch is from "a tower high above Earth's surface"; the default launch height is 300 m (Grok Audit21 P7).
  • Help code snippets are tested in the main test process, not in isolated subprocesses.
  • The Related Programs claims about Orbit, RelativisticOrbit, Binary and Atmosphere have not been cross-checked against those programs.
  • There is no requirements.txt (a suite-wide item; Grok Audit21 P4).
  • A negative option value written in scientific notation must use the = form: --vInit=-1e5 is accepted, but --vInit -1e5 is rejected.
