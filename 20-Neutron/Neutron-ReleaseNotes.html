Neutron 1.3.0 Release Notes

Version: 1.3.0
Build: b2c0f0597478
Date: 2026-09-16

What changed

  • All seven model, integration, and display settings are available through python main.py --help and command-line flags. Omitting a flag uses the supplied three-parameter polytropic model and numerical defaults.
  • Select --output_type pressure, density, or mass. Use --log_y for pressure or density; the mass plot remains linear even when a logarithmic axis is requested.
  • The Help file includes runnable commands for each suggested exercise, including convergence, low-mass results, and controlled equation-of-state comparisons. Experiments requiring a continuous sequence or the separate Star program still require additional analysis or code.
  • The Sample Outputs guide was synchronized with this version and build and now gives runnable commands and the default console summary.

Scope

The TOV solver remains a static educational model with one polytropic equation of state. Changing the polytrope can yield mathematical equilibria outside the physical domain represented by real neutron-star matter; read the causality and compactness diagnostics when interpreting results.
