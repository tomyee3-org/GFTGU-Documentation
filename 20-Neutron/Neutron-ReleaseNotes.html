Neutron 1.2.0 Release Notes

Version: 1.2.0
Build: 685bb0e10e01

Release Status

Version 1.2.0 concludes a kickoff maintenance review followed by independent adversarial review by Microsoft Copilot and Google Gemini and a final remediation pass by Codex. The reviewers examined the Tolman-Oppenheimer-Volkoff equations, equation-of-state implementation, surface-location method, numerical stability, validation and error handling, Help-file accuracy, Version/Build synchronization, regression coverage, and extreme-range behavior. All reported release-blocking defects have been corrected. The program is approved for release and is suitable for student use within the educational scope and limitations described below.

Major Improvements in This Release

  • Corrected the stellar-surface locator by replacing a pressure-tangent extrapolation with a surface estimate based on the regular polytropic variable q = p(gamma-1)/gamma, substantially reducing systematic radius bias.
  • Added guarded arithmetic and controlled failure handling throughout the central expansion, TOV derivative evaluation, and RK4 integration pipeline to prevent raw floating-point exceptions from escaping the public solver interface.
  • Added validation of the complete TOV denominator to prevent underflow-related division failures in extreme parameter regimes.
  • Introduced a dedicated SurfaceCrossingError so that RK4 surface detection no longer masks unrelated numerical or validation failures.
  • Reworked several calculations into logarithmic form, including EOS inversion, radial-scale evaluation, and central sound-speed diagnostics, reducing avoidable overflow and underflow risk.
  • Added explicit causality diagnostics reporting the central sound speed relative to the speed of light and whether the adopted toy EOS satisfies the causality condition.
  • Made plotting behavior more student-friendly by accepting case-insensitive output selections such as "pressure", " DENSITY ", and "mAsS".
  • Added a warning when log_y=True is requested for a mass plot, eliminating the previous silent override.
  • Documented the scientific reason that gamma = 1 is not accepted by this solver and clarified the limitations of representing self-bound matter with a simple polytropic EOS.
  • Added BUILD_ID verification across the four core program modules and synchronized Version/Build reporting with the Help file and runtime output.

Test Suite Growth

A comprehensive regression suite was created during kickoff and expanded throughout the audit process. The final release includes 107 automated tests covering physics equations, central expansions, RK4 integration, surface-location accuracy, plotting behavior, validation logic, Build-ID reproduction, Help-file synchronization, command-line execution, and Python compatibility checks.

The final suite includes deterministic extreme-range parameter sweeps, exact regression tests for all audit-discovered robustness defects, independent reference integrations using the regular surface variable, and surface-verification cases spanning multiple polytropic exponents. All 107 tests pass in both the canonical tests/ layout and a flattened upload layout. Independent audit reviews concluded that the previously reported numerical-robustness defects have been corrected and that no new release-blocking defects remain.

Known Limitations

  • Intended for education and conceptual exploration rather than precision neutron-star modeling or research-grade equation-of-state studies.
  • The EOS is a single pedagogical polytrope and does not represent modern crust-plus-core, piecewise-polytropic, or tabulated nuclear-matter equations of state.
  • The model is static, spherically symmetric, isotropic, nonrotating, and computes equilibrium configurations only.
  • The program does not evolve unstable stars, model collapse, compute quasi-normal modes, or simulate black-hole formation.
  • The reported mass is the TOV gravitational mass function. Baryonic mass, binding energy, tidal deformability, and rotational effects are not computed.
  • A failed causality diagnostic indicates breakdown of the assumed toy EOS rather than a prediction of superluminal propagation in real neutron-star matter.
  • The onset of instability along a sequence is inferred through the usual turning-point interpretation; no independent radial-mode stability calculation is performed.
  • The Help file loads MathJax from a public CDN. Offline, the explanatory text remains available but equations appear as raw LaTeX source rather than typeset mathematics.

Known Minor Maintenance Items

  • The source and tests parse successfully using Python 3.10 grammar and execute successfully under the audit environment's Python 3.12 interpreter. Running the complete suite under a native Python 3.10 runtime remains a desirable non-blocking verification step.
  • The deterministic extreme-range sweeps verify exception discipline and controlled failure behavior; they are not intended to establish physical validity across the entire sampled parameter space.
  • The independent q-reference integration used for surface verification exists within the regression suite and is not distributed as a separate user-facing utility.
