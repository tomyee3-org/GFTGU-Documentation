Major Improvements in This Release

Version 1.6.0 (Audit42 response):

  • The temperature-change cap now bounds |Delta T| by 5% of the temperature at the start of the step, not of min(T, T_target). The Audit41 300 K / 3000 K sawtooth at 8000 m stays within 0.02% of the exact piecewise integral. The Audit42 300 K / 30000 K counterexample, which 1.5.1 refused with a restart RuntimeError, now finishes (18,298 samples, 0.19 s) 0.002% from the exact integral. Disabling the cap restores a greater than 10% error on both sawtooths.
  • If the 5% cap spends the 50,000-point budget before pressure reaches zero, the driver raises a budget error instead of doubling the Euler step 25 times. Doubling cannot enlarge a temperature-capped step.
  • get_temp() re-validates the whole profile on every public call. An interior edit of h, T or power after validate() is a ValueError. The integrator uses a trusted interpolation path after one validation, so a 20,000-node run stays fast.
  • The suite audits scientific claims in Atmosphere-claude.html even when Atmosphere-grok.html is primary, including the isothermal 0.7144 Pa figure. Duplicate Help copies on the search path must match byte-for-byte.
  • Every run prints a Numerical top line. Both Help files describe it. A test pins the printed line to the result arrays for the default run and the 20 km profile. The 5% cap constant is pinned in code and in the short Help.
  • MODEL_VERSION is 1.6.0 because printed output and steep-profile results changed (Audit42 A42-P3-03).

Version 1.5.1, carried forward:

  • Breakpoint landing; temperature-limited Euler steps; rejection of non-positive result arrays; --save_plot / --no_show; dual Help discovery.

Known Limitations

  • Educational constant-gravity, constant-composition ideal-gas model. Temperature is supplied, not computed.
  • First-order Euler: 2.93% low at 100 km for an isothermal 288.15 K atmosphere when the step is not enlarged. After a restart the step is coarser and that few-per-cent figure does not apply. A 0-3000 km isothermal run that restarts is about 83% low and prints no warning that the step was enlarged.
  • The T = beta p^0.5 continuation is a pedagogical closure. The printed Numerical top is a stopping rule and depends on the step.
  • A profile with more positive nodes than MAX_STEPS cannot finish, because the integrator lands on every node. An extremely steep, densely sampled profile can still exhaust the 50,000-point budget under the 5% cap.
  • U.S. Standard Atmosphere 1976 layer-base pressures are a secondary-source fixture. Venus values are from a secondary compilation. Mars and Jupiter are round-number illustrations. The seven NRLMSIS temperatures are for one date and place. Those fixtures are consistency checks, not primary-source validation.
  • A checkpoint outside the positive-pressure domain has no model pressure.
  • Help files load MathJax from a public CDN.

Known Minor Maintenance Items

  • M_PROTON is absent; a direct importer gets AttributeError.
  • Some test method names still say molecular weight.
  • Long-Help Experiments 6 and 7 still give no numerical check values. Experiment 8 still asks for the surface-temperature step to be restored without quoting an expected result.
  • --save_plot . writes a hidden .png; a path without a suffix is written as PATH.png by Matplotlib.
  • Chapter 7 references remain in both Help files by the same standing decision as 1.5.1: the badge names the book chapter the program belongs to. Confirm with Prof. Schutz before a wider release if that rule should change.
