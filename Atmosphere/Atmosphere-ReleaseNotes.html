Atmosphere 1.4.0 Release Notes

Version: 1.4.0
Build: 95f43226e01f
Date: 2026-09-20

Release Status

Version 1.4.0 follows 1.2.1 through two rounds of changes: a Beats-layout Help file with three maintenance items (1.3.0), and a response to independent review by Codex and Grok that corrected the unit of the mean molecular mass and the step used in cold layers (1.4.0). A further review by Codex and Grok reproduced the 177-test suite, confirmed the molecular-mass correction and the improvement in cold layers, and reported the three open bugs below. Grok recommended accepting 1.4.0. Codex recommended holding it until OB-1 is resolved or the Help's error statement is narrowed. None of the three bugs is reached by the default run or by any command shown in the Help. These notes replace the 1.2.1 notes; the earlier notes are not reproduced.

Open Bugs

  • OB-1 (P2, Codex A22-P2-01). Pressure can be silently far below the exact integral when temperature breakpoints are closer together than the altitude step; the Help's stated error bound does not hold for such a profile.
    Reproduction: run AtmosphereModel (g = 9.81, μ = 28.97, p0 = 101300 Pa) on 100 repeated cells of 2.9256 m, each with 20 K at both edges and 2000 K at 10−6 of a cell in from each edge (301 points); the checkpoint at 292.56 m is 39% below the exact piecewise-linear integral of Eq. (7.3) (10 cells: 4.8% low), with no warning.
  • OB-2 (P3, Codex A22-P3-01). extract_checkpoints() and extract_output() accept a physically invalid AtmosphereResult.
    Reproduction: altitudes [−1e308, 1e308] with pressures [10, 1] give pressure 10 at a checkpoint of 0 m (correct value 5.5); pressures [−10, −9] or temperatures [300, 0] are accepted by extract_output() without error.
  • OB-3 (P3, Codex A22-P3-02). TemperatureProfile.get_temp() raises IndexError or ZeroDivisionError, not ValueError, for an invalid or later-modified profile.
    Reproduction: TemperatureProfile([], []).get_temp(0, 1e5) raises IndexError; TemperatureProfile([0, 0], [300, 200]).get_temp(0, 1e5) raises ZeroDivisionError. AtmosphereModel and the command line are not affected.

Major Improvements in This Release

Version 1.3.0:

  • The Help file now uses the Beats layout: eight Beats (0–7), each with a command, a table or plot to inspect, three tasks and the equation those observations lead to. Governing Equations is now an index.
  • AtmosphereModel keeps its own copy of the inputs and validates it again in run(), so later changes to the caller's lists no longer alter a run.
  • A list option may begin with a negative altitude when given as a separate argument, for example --h_points -1000,0,10000.
  • The Help's abbreviated main.py excerpt now shows the planet name and output type in the status line.

Version 1.4.0:

  • The mean molecular mass μ is now in atomic mass units; the former code multiplied the atomic-mass-unit value 28.97 by the proton mass. kB is the exact SI value, and M_PROTON is replaced by ATOMIC_MASS_UNIT. Default surface density is 1.2249 kg m−3 (was 1.2325); the Earth scale height at 288.15 K is 8430 m (was 8378 m).
  • The first altitude step is Hmin/200 at the coldest temperature the profile reaches above the reference level (was H/200 at the surface temperature). Four cold-layer profiles tested at one scale height improve from 11–70% low to 1.1–3.6% low. After a restart, a zero pressure at or below the highest supplied altitude now stops the run with an error instead of being reported as the top.
  • A wrong parameter object, a profile span that overflows the interpolation arithmetic, and a malformed AtmosphereResult (non-finite, unequal or non-increasing arrays) now raise ValueError. OB-2 and OB-3 record what is still accepted.
  • Help: one Mars gravity (3.72 m s−2) throughout; the statements that two scale-height readings are “independent” and that surface pressure “decides how much air there is” are corrected; every equation is tagged ODE, DERIVED, PRESCRIPTION or CLOSURE; Experiments 3, 4, 5, 8 and 9 give values to check.
  • Behaviour change to check if you scripted an earlier version: in the default run the first step goes from 41.89 m to 27.35 m, the stored points from 13,653 to 20,933, and the last altitude from 571,913 m to 572,418 m; pressures are higher by 0.9% at 10 km, rising to 22.9% at 500 km. Sample outputs were regenerated for 1.4.0.

Test Suite Growth

82 → 132 → 177 automated tests (1.2.1 → 1.3.0 → 1.4.0). The suite is run once from tests/ with RuntimeWarning promoted to an error; all 177 pass under CPython 3.11 in about 35 s, and both Audit22 reviewers reproduced this result. No test was removed. Seven of the original 82 were edited for the constant rename and recomputed regression values, and one of those was re-expressed with exact powers of two while asserting the same thing.

New coverage: the constants and an independent dry-air density coefficient; the step rule and fixed accuracy thresholds for cooling profiles against the exact piecewise-linear integral; the restart guard; span, parameter-object and result validation; fixtures for the U.S. Standard Atmosphere 1976, Venus and NRLMSIS values; 96 generated edge profiles; and the Help file (every command shown is run, quoted numbers are tied to live runs and to the sentence that uses them, equation tags, and exercise check values). 66 hand-made mutants of the program and Help were used to check the tests; all 66 are detected, after two tests were added for the two that were first missed.

Known Limitations

  • Educational constant-gravity, constant-composition ideal-gas model. The temperature profile is supplied, not computed. Not an atmosphere forecast.
  • The first-order Euler method accumulates error that grows with height (2.93% low at 100 km for an isothermal 288.15 K atmosphere). A profile that exhausts the 50,000-point budget restarts with a larger step.
  • The upper continuation T = βp0.5 is a pedagogical closure. The computed top is a stopping rule, and its altitude depends on the step (it moved 505 m in 1.4.0).
  • The Beat 6 U.S. Standard Atmosphere 1976 layer-base pressures are a test fixture transcribed from a secondary reproduction of the layer table and checked against the standard's defining constants (agreement better than 3 parts per million). The NTRS scan of the primary tables is of poor quality and was not used as a digitization source.
  • The Venus temperatures and the two published pressures in Beat 5 come from the Wikipedia article “Atmosphere of Venus,” a secondary compilation, not VIRA. The Mars and Jupiter profiles are round-number illustrations.
  • The seven rounded 100–500 km NRLMSIS 2.0 temperatures are illustrative and specific to 15 October 2024, 12:00 UTC, 55° N, 45° E. The CCMC run identifier, indices and raw output are not archived. The source fixtures are consistency checks, not primary-source validation.
  • A checkpoint outside the computed positive-pressure domain has no model pressure or p/T; the report says so.
  • Extreme parameter combinations that exceed the floating-point domain are rejected with an error.
  • The Help file loads MathJax from a public CDN. Offline, formulas appear as TeX source.

Known Minor Maintenance Items

  • M_PROTON no longer exists in physics_atmosphere; a direct caller importing it gets AttributeError. Whether this is a 1.x or a 2.0.0 change is undecided (Codex asked for the supported API to be defined; Grok considered 1.4.0 right).
  • The Help refers to “the six rounded temperatures” of the NRLMSIS run (Parameters); there are seven (100, 150, 200, 250, 300, 400 and 500 km).
  • The Help says the p/T column “is the density in different units” (Printed Checkpoints, Beat 1); density is p/T multiplied by μmu/kB.
  • Beat 6 says the coefficient of Eq. (7.3) “carries no rounding error of its own”; the rounded input μ and the measured atomic mass constant are part of it.
  • “Mean molecular weight” still appears in main.py, driver_atmosphere.py and some Help passages; elsewhere the term is “mean molecular mass.”
  • Experiments 6 and 7 give no numerical values to check. Experiment 8 asks for the surface-temperature step to be restored but gives no expected result.
  • Beat 6 quotes 3.2% at 86 km (the Euler error in ln p) directly under a table whose 86 km ratio to the standard atmosphere is 18% low; the two can be read as one number.
  • The Help gives mu to four figures (1.6605×10−27 kg); the code uses the full CODATA value.
  • There is no option to save a plot to a file or to run without a plot window.
  • The generated-profile accuracy test bounds the error only for its own profile families, not for every accepted profile (see OB-1).
