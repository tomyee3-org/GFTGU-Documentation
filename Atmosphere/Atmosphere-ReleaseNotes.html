Major Improvements in This Release

Version 1.6.0 (Audit43 response, this build):

  • Long-Help scientific tests load Atmosphere-claude.html whenever that file exists, and short-Help tests load Atmosphere-grok.html whenever that file exists. They no longer depend on which file is primary. Worked claims such as Experiment 8's 30843 Pa and Beat 6's 0.7144 Pa are checked in the shipped dual-Help layout.
  • A valid in-place edit of any supplied altitude, any supplied temperature, or power drops the cached upper-atmosphere coefficient. The Codex sequence that changed T[-1] from 300 K to 600 K after an above-profile query now continues from 600 K.
  • If a pass spends the 50,000-point budget while every Euler step was already shorter than the nominal increment, the driver raises a budget error after that one pass. It does not double the step 25 times. A tall profile that still takes unconstrained steps continues to restart. The 10 m, 801-node 300 K / 30000 K sounding now fails in one pass instead of about 1.25 million steps.
  • MIN_STEP_TO_SCALE_HEIGHT is the named 1e-5 exemption. A micrometre-wide 20 K / 2000 K edge uses more stored points when the exemption is removed. An extreme but valid finite profile that would shrink the step to zero raises a range error instead of blaming the user-supplied dh.

Version 1.6.0 (Audit42 response, carried forward):

  • The temperature-change cap bounds |Delta T| by 5% of the temperature at the start of the step, not of min(T, T_target). The 300 K / 3000 K and 300 K / 30000 K sawtooths stay within 0.02% of the exact piecewise-linear integral.
  • get_temp() re-validates the whole profile on every public call. An invalid interior edit of h, T or power is a ValueError. The integrator validates once and then uses the trusted interpolator.
  • Every run prints a Numerical top line. MODEL_VERSION is 1.6.0 because printed output and steep-profile results changed relative to 1.5.1.

Version 1.5.1, carried forward:

  • Breakpoint landing; rejection of non-positive result arrays; --save_plot / --no_show; dual Help discovery.

Known Limitations

  • Educational constant-gravity, constant-composition ideal-gas model. Temperature is supplied, not computed.
  • First-order Euler: 2.93% low at 100 km for an isothermal 288.15 K atmosphere when the step is not enlarged. After a restart the step is coarser and that few-per-cent figure does not apply. A 0-3000 km isothermal run that restarts is about 83% low and prints no warning that the step was enlarged.
  • The T = beta p^0.5 continuation is a pedagogical closure. The printed Numerical top is a stopping rule and depends on the step.
  • A profile with more positive nodes than MAX_STEPS cannot finish, because the integrator lands on every node. An extremely steep, densely sampled profile can still exhaust the 50,000-point budget under the 5% cap; if every step in that pass was already shorter than the nominal increment the error is raised after one pass.
  • U.S. Standard Atmosphere 1976 layer-base pressures are a secondary-source fixture. Venus values are from a secondary compilation. Mars and Jupiter are round-number illustrations. The seven NRLMSIS temperatures are for one date and place. Those fixtures are consistency checks, not primary-source validation.
  • A checkpoint outside the positive-pressure domain has no model pressure.
  • Help files load MathJax from a public CDN.
  • Public get_temp() scans the whole profile on every call (O(n)). The driver is unaffected because it validates once.

Known Minor Maintenance Items

  • M_PROTON is absent; a direct importer gets AttributeError.
  • Some test method names still say molecular weight.
  • Long-Help Experiments 6 and 7 still give no numerical check values. Experiment 8 still asks for the surface-temperature step to be restored without quoting an expected result.
  • --save_plot . writes a hidden .png; a path without a suffix is written as PATH.png by Matplotlib.
  • Both Help files still carry first-edition Chapter 7 equation tags. Whether a Help file should name a book chapter is an open question for Prof. Schutz; the badges are unchanged until he decides. They are not a standing program rule.
