Multiple 1.3.0 Release Notes

Version: 1.3.0
Build: 492bd8ed6eb1
Date: 2026-09-16

Changes

  • python main.py --help lists all initial conditions, integration controls, and display settings. Use --masses_solar 1,1, quoted triples such as --positions_init '5e10,0,0;-5e10,0,0', and the selector --animation_mode current_positions. Defaults reproduce the supplied three-body scenario.
  • The console prints initial and final conservation totals and the existing maximum drifts to five significant figures. Eleven further sets at fractions 0.0 through 1.0 of the actual integrated run show total energy E, boost-independent internal energy E_internal, kinetic energy K, three-component linear momentum P, and three-component angular momentum L. These samples interpolate diagnostics quadratically across accepted integration states when three states exist and are available in both plot modes.
  • Both static trajectory plots and the animation show a small gray unboxed display-frame label. Animation interpolated-frame totals remain as separate unobtrusive text; F still switches COM and user display frames.
  • The Help and Sample Outputs guide show runnable command lines and synchronized figures and results.

Scope

Newtonian point masses only. These sample diagnostics interpolate computed totals; the maximum-drift summary continues to measure accepted states directly. Numerical integration can drift in close encounters; compare integration settings for convergence. COM is a display translation; integration diagnostics remain in user input coordinates. Binary identification and quantitative comparison to MercPert require analysis beyond parameter changes.
