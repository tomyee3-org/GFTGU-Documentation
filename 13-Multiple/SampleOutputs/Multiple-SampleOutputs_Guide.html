What the program calculates

Multiple integrates the Newtonian motion of any chosen number of mutually gravitating point masses in three dimensions. No body is privileged: every body’s acceleration includes the pairwise contribution of every other body.

The adaptive predictor–corrector reports energy, linear-momentum, and angular-momentum drift. Output can be a complete static trajectory plot or an interactive animation with current positions or recent trails, fixed or automatic equal-scale axes, and xy, xz, or yz projection.

What it shows

  • Keyboard controls allow pause/resume, single-frame stepping, and jumps to the first or final frame.

Notes for evaluation

  • Model scope: point masses interact through Newtonian gravity; there is no collision merger, tidal physics, gas, radiation, or other dissipation.
  • Numerical method: a predictor and iterated trapezoidal corrector use adaptive timestep reduction during rapid changes or failed convergence, then gradually recover toward the user’s dt ceiling.
  • Memory choices: trajectory mode stores every accepted state; animation mode stores only uniformly timed frames, so its memory use is governed mainly by frame count.
  • Three-dimensional display: the calculation is always three-dimensional, while the selectable xy, xz, and yz views are two-dimensional projections.
  • Suggested investigations: the documentation includes a two-body sanity check, mass changes, out-of-plane encounters, convergence, centre-of-mass transformations, binary hardening, small clusters, comparison with MercPert, and a toy galaxy collision.
  • Build verification: the executable and documentation both identify version 1.1.2, build bb853c24c69e. Following the credit-conscious workflow requested for this guide series, no regression suite was run.

Image and source provenance

The trajectories and diagnostics were generated with the supplied run_simulation(), plot_trajectories(), animate_multiple(), and plot_energy_drift() functions. The animation still was reconstructed from the stored trajectory at the same uniform physical frame times and with the same cubic-Hermite interpolation used by animation mode. Each embedded image is a 256-color indexed PNG (mode P): default: 623×700, 249 colors, 22.3 KiB; trails: 700×700, 238 colors, 13.2 KiB; energy: 943×700, 256 colors, 17.9 KiB; out_of_plane: 924×253, 239 colors, 14.5 KiB. The combined embedded PNG payload is 67.8 KiB, compared with 192.0 KiB before palette conversion—a reduction of 64.7%.
