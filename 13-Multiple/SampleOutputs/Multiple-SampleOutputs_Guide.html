What the program calculates

Multiple integrates Newtonian point-mass motion in three dimensions. The integrator always uses the user-supplied inertial coordinates. Plots default to the center-of-mass display frame, which subtracts the instantaneous R_CM for viewing only. Console totals report user-frame E, E_internal, P, and L.

Figure 2 — Same physics, user frame versus COM display

Every shipped velocity was increased by u = (1.0e5, 0, 0) m/s. The printed momentum must be P_new = P_old + M u = (2.7e5, -3.0e4, 0) m/s, not M u = (3.0e5, 0, 0). The left panel is the raw user-frame plot; the right panel is the same stored states after the COM display translation.

Relative shapes match. Only the user-frame panel shows the bulk drift.

P after boost: (2.70e5, −3.00e4, 0) m/s

Figure 3 — User-frame total-energy drift

Drift is computed from accepted integration states in the user frame. Changing display_frame does not change this curve. E_internal = E − |P|^2/(2M) removes the bulk kinetic piece without rewriting the initial data.

Figure 4 — Animation still with discrete frame note

The wheat box is the discrete frame note. Totals are stacked as E/E_int, then P, then L, and are labeled interpolated-frame totals because animation samples are cubic-Hermite display states. Press F to switch frames; the note becomes “Switched — Display frame: …”.

Figure 5 — Out-of-plane encounter, xz projection

Body 3 was given an extra 5 km/s in z. COM display keeps the origin on the mass-weighted mean while the xz view shows the vertical excursion.

Added z speed: 5.0 km/s  |  Projection: xz

Notes for evaluation

  • Model scope: Newtonian point masses; no collisions, tides, gas, or relativity.
  • Frames: integration and printed diagnostics stay in the user inertial frame; COM is a reversible display translation of positions only.
  • Shipped momentum: the default state already has P = (−3.0e4, −3.0e4, 0) m/s in scaled units.
  • Authoritative conservation numbers are the console initial/final totals and the maximum-drift line, not the interpolated animation overlay.
  • Build verification: executable and this guide identify version 1.2.2, build e29d630e7cf0.
