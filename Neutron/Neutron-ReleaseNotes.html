Release Status

This release is Neutron 1.3.1, build 2cd414a64b3a. It covers the two most recent code-changing rounds, the Audit23 response and the Audit24 response (both 2026-09-24), both of which revised Neutron-claude.html only; the four program modules (main.py, physics_neutron.py, driver_neutron.py, plot_neutron.py) are byte-identical across both rounds and back to Kickoff2.

A subsequent round, Audit25 (2026-09-23/24), reviewed the Audit24 response and changed nothing; it is mentioned here only because it set this release's open items. Grok's Audit25 review found no open item, confirmed the four program modules and the packaged test suite unchanged, and recommends freezing Neutron-claude.html and moving on to this release's documents. Codex's Audit25 review likewise established no new program-code defect and did not request another review cycle; it raised one P2 and one P3 finding against Neutron-claude.html and its test suite, both listed under Open Bugs below. Correcting them is deliberately deferred to a later round; this release documents them rather than fixing them.

Major Improvements in This Release

  • Beat 1's interior-ranking discussion now states the crossover radii precisely (compactness overtakes the pressure/energy ratio near r/R≈0.287 and the pressure-source ratio near r/R≈0.420) instead of a mis-located "around the halfway point", and both this paragraph and the Eq. 2 discussion consistently describe the default model as "the default toy-star model" rather than implying it is a real stellar interior.
  • Beat 1 now states the correct r→0 limit of the TOV-to-Newtonian pressure-gradient ratio, (1+η)(1+3η)≈1.979, and explains that the classical equation stays off by nearly a factor of two arbitrarily close to the center of this model, correcting a prior sentence that wrongly implied the classical equation becomes exact there.
  • Beats 4 and 5 now describe the surface-location extrapolation (Eq. 7) as "linear (tangent-line)" in formula shape but second-order accurate in error, correcting an earlier "first-order" description, and state its accuracy is demonstrated by evidence (a roughly fourfold error reduction per grid doubling) rather than asserted.
  • Beat 5 now states REF_R's actual role and provenance precisely: it is a fixed benchmark checked against the production solver's own surface-location regression, not reproduced bit-for-bit by a single run of the reference integrator shown on the page (the two differ by roughly a micrometre), and a new executable test, test_q_reference_model_matches_default_reference_constant, checks that specific gap directly.
  • A stale docstring claim that the interior pressure-dominant ranking holds "through most of" the star's volume was corrected to state the actual crossover radii; the volume inside the inner crossover is about 7% of the star's total, not most of it.
  • None of these changes altered any program module or any number the program prints; they are corrections to the Help file's prose and, in one case, to a test's documentation and one test-file comment's stated provenance.

Test Suite Growth

All counts below are for Neutron 1.3.1, build 2cd414a64b3a; the four program modules did not change across these rounds. The suite grew from 122 tests + 5 subtests, to 125 + 5 after the Audit23 response (three new Help-content regression tests), to 127 + 5 after the Audit24 response (one new physics-behavior test executing the independent reference integrator against REFERENCE_RADIUS_M, and one new Help-content lock). No test assertion was weakened or removed in either round.

The suite is run with pytest and passes in both the sibling-repo layout (GFTGU-Programs/Neutron beside GFTGU-Documentation/Neutron) and the flattened code-review layout used for packaged submissions, on Python 3.12. It has also been verified, as of Kickoff2, under native Python 3.10.20, 3.11.15, 3.12.3 and 3.13.13 interpreters, not only the 3.12 audit environment.

Known Limitations

  • The equation of state is a single polytrope, not a modern piecewise or tabulated nuclear-matter model; it cannot represent a crust, neutron drip, or a composition change with radius.
  • The star is modeled as static, spherically symmetric, isotropic and non-rotating; the program has no setting for rotation, a magnetic field, finite temperature, tidal deformability, or separate baryonic-versus-gravitational mass bookkeeping.
  • The program computes equilibrium configurations only. It can display a model on either side of the mass-maximum turnover described in Beat 7, but it does not evolve an unstable star, model a collapse, or compute quasi-normal modes.
  • The deterministic extreme-range sweeps in the test suite verify exception discipline and controlled failure behavior; they are not intended to establish physical validity across the entire sampled parameter space.

Known Minor Maintenance Items

  • The independent q-reference integration used for surface verification is named and described in Beat 5, and an executable test now checks it against REFERENCE_RADIUS_M at the default model's own parameters, but it is still not distributed as a separate user-facing utility. Shipping it as a small student-facing tool remains optional future work.
  • Beat 7 identifies a mass-maximum turnover between central pressures of 1035 and 1036 Pa but notes the program does not itself test the associated instability dynamically. An explicit dynamic stability test of that turnover remains optional future work.
