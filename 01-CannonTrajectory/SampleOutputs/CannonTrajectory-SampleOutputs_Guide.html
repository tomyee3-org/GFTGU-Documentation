Purpose. These four figures give a compact visual survey of CannonTrajectory and its two numerical integration methods. The program models a projectile near Earth's surface using constant standard gravity, a flat ground plane, and no air resistance. It is deliberately elementary: students can compare numerical trajectories with exact constant-acceleration results, separate timestep sampling from integration error, and build parameter studies with a small amount of Python.

1. The default 45° trajectory

Figure: CannonTrajectory-Sample1-Default.png

python main.py

# Settings in main.py:
speed=100.0, angle_deg=45.0, dt=0.1,
method="improved", max_steps=100_000

The standard output for a 100 m/s launch at 45°. Equal physical scales on the two axes preserve the true parabolic shape; the orange point marks the launch.

What it shows

  • In the ideal constant-gravity model, 45° gives the greatest range for a fixed launch speed.
  • The improved-Euler method reproduces the exact position and velocity at each sampled time for this constant-acceleration problem, apart from roundoff.
  • The trajectory intentionally includes the first sampled point below ground. That endpoint is not the physical landing point.
  • Linear interpolation between the last non-negative and first negative heights gives a much better range estimate.

Headline values

  • Analytic flight time: 14.4210 s.
  • Analytic maximum height: 254.929 m.
  • Analytic range: 1019.716 m; interpolated numerical range: 1019.708 m.
  • 146 stored points, including launch and the first below-ground sample at x = 1025.305 m, h = −5.619 m.

2. Overlay several trajectories

Figure: CannonTrajectory-Sample2-AngleOverlay.png

from driver_cannon import run_cannon_trajectory
from plot_cannon import plot_cannon_overlay

trajectories = []
for angle in (15, 30, 45, 60, 75):
    xs, hs = run_cannon_trajectory(
        speed=100, angle_deg=angle, dt=0.1
    )
    trajectories.append((f"{angle} degrees", xs, hs))

plot_cannon_overlay(trajectories)

The documented “Overlay several trajectories” experiment: five launches at the same 100 m/s speed and 0.1 s timestep, displayed together by the supported overlay helper.

What it shows

  • Complementary angles have equal analytic ranges: 15° pairs with 75°, and 30° pairs with 60°.
  • The members of each pair follow very different paths and have different maximum heights and flight times.
  • The 45° trajectory has the greatest range, but not the greatest height or longest time aloft.
  • Slight differences between raw sampled endpoints are caused by the fixed sampling times, not by a failure of the complementary-angle result.

Headline values

  • 15° and 75° analytic range: 509.858 m.
  • 30° and 60° analytic range: 883.100 m.
  • 45° analytic range: 1019.716 m.
  • Analytic maximum heights rise from 34.154 m at 15° to 475.704 m at 75°.

3. Forward Euler versus improved Euler

Figure: CannonTrajectory-Sample3-MethodOverlay.png

trajectories = []
labels = {"euler": "Forward Euler", "improved": "Improved Euler"}
for method in ("euler", "improved"):
    xs, hs = run_cannon_trajectory(
        speed=100, angle_deg=45, dt=0.5, method=method
    )
    trajectories.append((f"{labels[method]}, dt = 0.5 s", xs, hs))

plot_cannon_overlay(trajectories)

The same 100 m/s, 45° launch calculated with a deliberately coarse 0.5 s timestep. Forward Euler places the projectile too high because each height update uses the vertical velocity from the beginning of the interval.

What it shows

  • Forward Euler accumulates a first-order vertical-position error and therefore predicts too long a flight and too great a range.
  • Improved Euler averages the initial and predicted derivatives, reproducing the exact sampled parabola for constant acceleration.
  • The small remaining difference between its interpolated and analytic ranges comes from linearly locating a quadratic ground crossing.
  • Reducing the timestep makes the forward-Euler path converge toward the improved-Euler path.

Headline values

  • Analytic range: 1019.716 m.
  • Forward-Euler interpolated range at dt = 0.5 s: 1054.910 m.
  • Improved-Euler interpolated range at dt = 0.5 s: 1019.549 m.
  • The coarse-step comparison uses 31 stored points for forward Euler and 30 for improved Euler.

4. Effect of muzzle speed

Figure: CannonTrajectory-Sample4-SpeedOverlay.png

trajectories = []
for speed in (50, 75, 100):
    xs, hs = run_cannon_trajectory(
        speed=speed, angle_deg=45, dt=0.1
    )
    trajectories.append((f"{speed} m/s", xs, hs))

plot_cannon_overlay(trajectories)

Three 45° launches calculated with improved Euler at dt = 0.1 s. Both horizontal range and maximum height grow as the square of launch speed in this ideal model.

What it shows

  • At fixed angle, the trajectory retains the same scaled parabolic shape as speed changes.
  • Range and maximum height are proportional to v₀², while flight time is proportional to v₀.
  • Doubling the speed from 50 to 100 m/s quadruples the analytic range and maximum height.
  • At sufficiently large distances, the model's flat Earth, constant gravity, and absent atmosphere become important limitations.

Headline values

  • 50 m/s: analytic range 254.929 m; maximum height 63.732 m.
  • 75 m/s: analytic range 573.590 m; maximum height 143.398 m.
  • 100 m/s: analytic range 1019.716 m; maximum height 254.929 m.
  • The 50, 75, and 100 m/s analytic flight times are 7.210, 10.816, and 14.421 s.

Notes for evaluation

  • The model uses conventional standard gravity, g = 9.80665 m/s², with no air resistance, wind, Earth curvature, rotation, or variation of gravity with altitude.
  • For ordinary experiments, users edit the settings passed to run_cannon_trajectory() in main.py; the command line itself provides only --version.
  • The program returns the launch point, every fixed-time sample, and the first point below ground. This intentional design exposes endpoint sampling error for the landing-interpolation exercise.
  • plot_cannon_overlay() accepts labeled (label, xs, hs) triples and supplies the shared axes, equal physical scaling, grid, launch marker, and legend.
  • The Help file provides seven experiments ranging from basic parameter exploration through landing interpolation, integrator accuracy, and a deliberately degraded update suggested by Prof. Schutz.
  • The supplied current build passes all 63 regression tests, including the run with runtime warnings promoted to errors.
