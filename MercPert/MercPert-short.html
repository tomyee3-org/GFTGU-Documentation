Start here

Put a small test particle near a Sun–companion binary, run a command, then compare the printed diagnostics with the blue trajectory. Follow Beats 0–9 in order on a first pass. Every command starts a fresh run from the MercPert program folder; close the plot window before the next one.

Mercury's input position and velocity are relative to the Sun, while the plotted positions use the system's centre of mass. The dashed red and green circles show the prescribed stellar paths; the solid blue curve is Mercury's calculated path. A crossing of coloured paths on the screen does not mean the bodies met at the same time.

Beat 0 · A test particle in a binary

Begin with the default: a 1-solar-mass Sun, a 0.1-solar-mass companion 0.7 astronomical units (AU) away, and Mercury 0.3 AU from the Sun with a 59,220 m/s sideways launch.

python main.py
Read these lines

The stellar period is 203.96 days. The run covers 231.48 days and 10,000 accepted steps; Mercury ranges from 0.30000 to 0.40762 AU from the Sun. Find the compact red circle, wider green circle, and blue loops. The stars move on set circles; Mercury responds to both of them.

The program solves Newton's equation for a massless third body: \(\ddot{\mathbf r}=-GM_\odot(\mathbf r-\mathbf r_\odot)/|\mathbf r-\mathbf r_\odot|^3-GM_c(\mathbf r-\mathbf r_c)/|\mathbf r-\mathbf r_c|^3\). Do not call the blue loops closed or stable from this finite run alone.

Practice task 1 revisits this launch.

Beat 1 · The binary is prescribed

Make the companion half as massive as the Sun. Watch what moves in the plot.

python main.py --m_planet_solar 0.5 --vy_init 54400
Check the geometry

The printed binary period is 174.66 days. The Sun's red circle has radius 0.23333 AU about the centre of mass; the companion's green one has radius 0.46667 AU. Their 0.7 AU separation remains fixed. Read both radii from the axes, not from Mercury's printed Sun-distance range (0.14420–0.31804 AU).

The stellar angular speed is \(\omega=\sqrt{G(M_\odot+M_c)/d^3}\). At \(t=0\) the Sun moves in the negative \(y\) direction. The 54,400 m/s input is relative to that moving Sun, so it is not Mercury's barycentric speed.

Practice task 2 tests the frame conversion.

Beat 2 · Switch the companion off

The companion mass must remain positive. Make it negligible and try a circular-speed launch, then the default faster launch.

python main.py --m_planet_solar 1e-12 --vy_init 54379.16
python main.py --m_planet_solar 1e-12
Compare

The first Sun-distance range prints 0.30000–0.30000 AU. The second prints 0.30000–0.43707 AU. The default companion in Beat 0 kept the same 59,220 m/s launch within 0.40762 AU over the same run.

For one Sun, \(v_c=\sqrt{GM_\odot/r}\). Starting at perihelion \(r_p\) with tangential speed \(v>v_c\), energy and angular momentum give \(r_a/r_p=[2-(v/v_c)^2]^{-1}(v/v_c)^2\), provided the launch remains bound. At \(r_p=0.3\) AU, this predicts 0.43707 AU for the second run.

Practice task 3 asks for a prediction before rerunning.

Beat 3 · Turn the companion back up

Keep the near-circular speed and multiply companion mass by ten on each run.

python main.py --m_planet_solar 0.001 --vy_init 54379.16
python main.py --m_planet_solar 0.01 --vy_init 54379.16
python main.py --m_planet_solar 0.1 --vy_init 54379.16
Subtract each range

The Sun-distance spreads are 0.00049, 0.00491 and 0.05020 AU. For these settings they grow by about a factor of ten each time the companion mass does. The relation is empirical over these three finite runs, not a promise for every mass or encounter.

The companion's direct acceleration relative to the Sun's pull scales as \((M_c/M_\odot)(r/\Delta)^2\), where \(\Delta\) is Mercury's distance from the companion. That ratio changes throughout the orbit; close passages can break the simple proportional pattern.

Practice task 4 tests where the trend stops.

Beat 4 · The one number that is conserved

Ask for the second plot: signed fractional change of the Jacobi constant in the rotating binary frame.

python main.py --show_jacobi_diagnostic
Read and look

The console gives a maximum absolute fractional Jacobi drift of 1.2305e-06. The second plot shows its sign, ranging about −1.23e-06 to +6.6e-08. Close the orbit window if it obscures the diagnostic window.

Ordinary inertial energy of Mercury can change because the moving stars exchange energy with it. In a frame turning with the binary, the stellar field is stationary and \(C=2(\mathbf r\times\mathbf v)_z\omega-v^2+2GM_\odot/r_\odot+2GM_c/r_c\) is conserved by the ideal equations. A small computed drift diagnoses numerical error; it does not prove the entire path is accurate.

Practice task 5 asks which plotted quantity is signed.

Beat 5 · Close encounters and the step controller

Run longer, then tighten the acceleration-change and corrector thresholds.

python main.py --max_steps 40000
python main.py --max_steps 40000 --eps1 0.01 --eps2 1e-5
Compare the runs

The first reaches 0.016704 AU from the Sun over 919.20 days; its accepted working timesteps range from 199.63 to 2000.0 s and its Jacobi drift reaches 0.0051623. The tighter run needs steps down to 39.907 s and reports drift 0.00022738, but covers only 852.41 days. The runs have unequal durations, so their drift maxima alone do not measure the benefit of the tighter tolerance. The blue path is much less regular than in Beat 0.

The controller rejects a proposed step when acceleration changes too much and iterates a predictor–corrector until its change is below eps2. dt is the maximum working step, not a guarantee that each accepted step is that long. Drift this large calls for convergence checks before quoting a close-encounter trajectory.

Practice task 6 probes the controller.

Beat 6 · Collision and escape

Make the companion as massive as the Sun for a collision, then try a launch that heads far outward.

python main.py --m_planet_solar 1
python main.py --x_init_au 0.45 --max_steps 30000
Read the stopping reason

The first stops at collision with Sun after 1920 steps and 41.543 days, at one nominal solar radius (0.0046505 AU); the black × marks that boundary crossing. The second reaches 11.531 AU from the Sun within 694.44 days, but its stopping reason is max_steps reached, not “escaped.”

A point mass has no physical surface in these equations. The positive Sun collision radius is a numerical stop; the companion's default collision radius is zero (disabled). A long outward track in a finite run is evidence of outward motion over that interval. The program does not certify permanent escape, and a positive instantaneous energy near moving stars would not by itself do so.

Practice task 7 asks for a finite-time criterion.

Beat 7 · Outside the binary

Place two equal Suns 1 AU apart and launch 2.5 AU from the Sun. Try a seemingly plausible relative speed, then include the Sun's motion.

python main.py --m_planet_solar 1 --binary_separation_au 1 --x_init_au 2.5 --vy_init 30000 --max_steps 40000
python main.py --m_planet_solar 1 --binary_separation_au 1 --x_init_au 2.5 --vy_init 50846 --max_steps 40000
Compare the blue paths

Mercury starts 2.0 AU from the barycentre. About 29,785 m/s would circle a point mass of two solar masses there. But the Sun moves initially at about −21,061 m/s in \(y\); the first relative speed makes only about 8,939 m/s barycentric, so Mercury falls into the binary. With 50,846 m/s relative to the Sun, it circles outside. Its Sun-distance range is 1.5463–2.6554 AU.

For a nearby binary, a point-mass circular estimate is only a starting guess. The pair's changing geometry still perturbs the outside orbit.

Practice task 8 checks the sign of the velocity conversion.

Beat 8 · How far to trust a run

Halve the maximum step on a smooth orbit; keep the simulated duration at 20 million seconds by changing max_steps.

python main.py
python main.py --dt 1000 --max_steps 20000
python main.py --dt 500 --max_steps 40000
Record drift

The three maximum fractional Jacobi drifts are 1.2305e-06, 3.0312e-07 and 7.5216e-08. The ratio is about four when dt halves, consistent with second-order convergence on this smooth run.

Now halve dt for the Sun-grazing run of Beat 5:

python main.py --max_steps 80000 --dt 1000

Its drift is 0.0051786, much like 0.0051623 at the larger cap. Close to the Sun, eps1 rather than the cap already controls the working step. Beat 5's tighter-eps1 run reported a smaller drift but covered less time. Match physical duration and inspect actual accepted steps when judging convergence.

Beat 9 · Where the model and the run stop

Try three invalid settings and one singular starting position.

python main.py --m_planet_solar 0
python main.py --eps2 0.1
python main.py --binary_separation_au 0.001
python main.py --x_init 0

The first three are rejected by the argument parser: masses must be positive, eps2 must be smaller than eps1, and the two collision radii must fit within the binary separation. The fourth passes parsing but starts exactly at the Sun's point-mass centre, where gravity is singular; it reports a MercPert error: message with no plot. An ordinary max_steps reached is not an error.

MercPert is planar, prescribes a circular binary, and neglects Mercury's mass, atmosphere, disks, tides, relativity and impact evolution. A finite-radius collision is interpolated along an accepted segment. Printed five-significant-digit numbers still need a timestep study before they can be trusted quantitatively.

Reading the output

The first console line gives version, build, accepted-step count and stopping reason. Next come the binary's circular period, Mercury's integration time, its minimum and maximum distance from the Sun, maximum absolute fractional Jacobi drift, and the smallest/largest accepted working timestep. A run at max_steps has that many accepted steps plus the initial state. A collision can stop sooner.

The orbit plot uses dashed red for Sun, dashed green for companion and solid blue for Mercury. A black × appears only for a configured collision. With --show_jacobi_diagnostic, the second plot shows signed \((C-C_0)/|C_0|\), whereas the console shows its maximum magnitude. If \(C_0=0\), the printed fractional drift is undefined. For a collision, the interpolated endpoint contributes to the printed drift. The Sample Outputs Guide provides representative figures and quoted values for Beats 0–8.

Practice tasks

  1. From Beat 0, compare the 231.48-day run with the binary's 203.96-day period. State what the blue loops do and what a single run cannot establish.
  2. Use Beat 1's mass ratio and 0.7 AU separation to calculate the two stellar orbit radii, then check them against the axes.
  3. Predict the isolated-Sun circular speed at 0.3 AU and the aphelion of the 59,220 m/s launch before running both Beat 2 commands.
  4. Extend Beat 3's companion-mass sequence to 0.3 and 0.5 solar masses. Record when the nearly proportional spread no longer holds.
  5. Explain why Beat 4's console drift is nonnegative while the plotted drift takes both signs.
  6. Repeat Beat 5 with a tighter eps1. Record both the smallest working step and the Jacobi drift; compare the actual simulated durations.
  7. For Beat 6's outward run, propose a finite observation interval and distance threshold for an operational “ejected during this run” label. Explain why that would not certify permanent escape.
  8. For Beat 7, add the Sun's initial barycentric y velocity to each Sun-relative input velocity and predict which launch can circle outside the binary.

Keep each command and its printed lines with your explanation. The fuller tutorial offers worked checks and additional open-ended experiments.
