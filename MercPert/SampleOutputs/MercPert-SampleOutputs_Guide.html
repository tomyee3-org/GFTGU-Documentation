Purpose. Read alongside the merged MercPert Help file. One regenerated figure illustrates each of Beats 0–8. Each section lists the exact current Help command, what the figure shows, and five headline values from that run. Beat 9 demonstrates errors and has no figure. All images are embedded.

Orbit plots use barycentric coordinates: dashed red for the Sun, dashed green for the companion, and solid blue for the test particle. Filled circles mark starts; a black × marks a configured collision. Figure 5 shows signed Jacobi drift instead of an orbit. Input positions and velocities are Sun-relative. Commands are run from the MercPert program folder; omitted options take the Help file’s listed defaults.

Beat 9 · Where the model and the run stop

These four commands produce no plot. The first three print parser usage and an error; the fourth reaches the singular-force check.

python main.py --m_planet_solar 0

Expected diagnostic: MercPert: error: argument --m_planet_solar: enter a number greater than zero

python main.py --eps2 0.1

Expected diagnostic: MercPert: error: --eps2 must be smaller than --eps1

python main.py --binary_separation_au 0.001

Expected diagnostic: MercPert: error: collision radii must sum to less than binary separation

python main.py --x_init 0

Expected diagnostic: MercPert error: Mercury has reached the Sun’s point-mass position; the Newtonian point-mass force is singular there.

Notes for evaluation

  • Model scope: a planar circular restricted three-body model. The test particle has no back-reaction on the prescribed binary; gas, pressure, tides, relativity and impact evolution are absent.
  • Input convention: the initial position and velocity are Sun-relative and are converted to barycentric coordinates before integration. Add the Sun’s barycentric velocity when estimating an outer-binary launch.
  • Numerical method: an Euler predictor and iterated trapezoidal corrector use adaptive steps. A small Jacobi drift is a useful check, not a proof of phase accuracy or of a later encounter outcome.
  • Collision handling: configurable moving circular boundaries can stop the trajectory. The default enables the nominal solar radius and disables the companion boundary; the printed drift includes an interpolated collision endpoint.
  • Termination: max_steps reached reports a step budget, not a stability or escape classification. Compare physical durations, accepted steps and tolerances before judging close-encounter results.
  • Practice Task 9 restores the 10:1, 0.3-AU binary application from Schutz’s Java documentation. Treat test-particle paths as a gravitational illustration; this program does not compute gas stripping, pressure, radiation or accretion-disk evolution.
  • The Help gallery uses the author’s six replacement illustrations, including the ejection/retrograde comparison and the near-L₂ example. This guide’s figures correspond to the terminal Beats and were generated separately.
