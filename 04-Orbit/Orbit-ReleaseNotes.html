Orbit 1.4.0 Release Notes

Version: 1.4.0
Build: c9fb119d6144

Release Status

Version 1.4.0 adds a complete command-line interface and expands the numerical summary with planar Keplerian orbital elements. The Newtonian inverse-square model, adaptive predictor-corrector algorithm, trajectory arrays, and five plot modes retain their previous behavior.

Command-Line Interface

  • Added command-line options for all ten driver inputs: --xInit, --yInit, --vxInit, --vyInit, --k, --dt0, --maxSteps, --eps1, --eps2, and --maxOrbits.
  • Added --output for the five display alternatives: orbit, velocity, position_time, velocity_time, and energy.
  • Documented every option in the main.py module description and in python main.py --help. Omitted options retain the established Mercury-like defaults.
  • Invalid physical or numerical settings now terminate with a concise Orbit: ... message.

Keplerian Elements

The program derives osculating elements from the initial Cartesian state and the selected central gravitational parameter. The summary reports:

  • conic classification: elliptic, parabolic, or hyperbolic;
  • eccentricity;
  • semimajor axis, using the standard negative value for a hyperbola;
  • semilatus rectum and periapsis radius;
  • apoapsis radius and Keplerian period for an ellipse;
  • periapsis longitude and initial true anomaly in the x-y plane when the orbit is not circular.

Inclination and longitude of the ascending node are not included because Orbit is a two-dimensional program. Periapsis direction and true anomaly are marked as undefined for a circular orbit. A parabola has no finite semimajor axis, apoapsis, or period; a hyperbola has no apoapsis or period.

Summary Output

  • All real-valued summary results are formatted to five significant digits. Exact integer counters remain integers.
  • The summary continues to report termination, accepted steps, elapsed simulated time, azimuthal revolutions, angular-step rejections, endpoint refinement trials, fractional and absolute energy drift, fractional and absolute angular-momentum drift, and closure residuals.
  • Closure radius and velocity fields are now printed as n/a when the endpoint is not an integral-revolution closure point, keeping the summary layout complete across run types.
  • A hyperbolic trajectory ending at maxSteps or a deliberately small maxOrbits target reports its final radius and final speed.

Known Limitations

  • Orbit models a test particle around a fixed point mass. It is not a general two-body or N-body simulation.
  • The force law is Newtonian. Relativistic effects, finite body sizes, atmospheric drag, radiation pressure, tides, and third-body perturbations are not included.
  • The reported elements are osculating elements calculated from the initial state. Numerical drift diagnostics and closure residuals describe the actual integrated trajectory.
  • Five-significant-digit display does not imply that every run is physically or numerically accurate to five significant digits. Students should use the reported conservation and closure diagnostics and repeat runs with tighter controls.
  • The singularity guard is numerical rather than a physical stellar or planetary surface.
