Start here

Planck2 lets you change a black body's temperature and see three related spectra: radiance per wavelength, radiance per frequency, and energy density per frequency. It accompanies Chapter 10, Investigations 10.1–10.3. You will run commands, read the five-line summary, and test where a numerical curve agrees with its exact integral.

Run commands from the folder containing main.py. Close each plot window before starting the next run. The equations use MathJax from the internet; the Python program runs offline.

Model boundary: this is an ideal black body at one temperature. There are no spectral absorption lines, nonunit emissivity, or radiative transfer.

Beat 0 · Look at one spectrum

Run. Start with the default 5900 K body, plotted as radiance per wavelength.

python main.py --T 5900 --quantity wavelength --n_steps 2000 --x_min 0.01 --x_max 100 --x_low 0.05 \
  --x_high 20 --y_frac_window 0.003

Observe. The console gives peak at x = 4.959505, Peak wavelength = 4.917033e-07 m, and both a numerical and an exact integral. The plot box also gives the sampled Peak value, which the console does not. Compare 2.187105e+07 with 2.187106e+07 in W m−2 sr−1.

Your turn. Move the cursor near the top of the curve. Which physical wavelength is at the maximum? Why might the cursor and the six-digit printed peak disagree slightly?

The dimensionless coordinate is \(x=hc/(\lambda kT)=h\nu/(kT)\). Planck's law supplies the curve; the printed peak is the largest sampled point, not a continuous optimizer.

Beat 1 · Change temperature

Run. Compare these separate wavelength plots and record each printed peak wavelength.

python main.py --T 3000
python main.py --T 5900
python main.py --T 10000

Observe. A hotter body peaks at a shorter wavelength. The product of temperature and peak wavelength should stay approximately fixed. The sampled \(x\) peak stays near 4.965 with a sufficiently fine grid.

Your turn. Multiply the first and third peak wavelength by their temperatures. How close are the products? The law for this plotted density follows from \(\lambda_{\rm peak}=hc/(x_5 kT)\), where \(x_5\approx4.965\).

Beat 2 · Change the horizontal density

Run. Ask for radiance per frequency at two temperatures.

python main.py --T 5900 --quantity frequency
python main.py --T 2.725 --quantity frequency

Observe. These horizontal axes are in hertz; the second run represents the cosmic microwave background as an ideal 2.725 K black body. Its frequency peak is much lower. The frequency peak has \(x_3\approx2.821\), whereas Beat 1 used \(x_5\approx4.965\).

Your turn. Calculate \(h\nu_{\rm peak}/(kT)\) from one printed frequency. Why is it wrong to turn the wavelength peak of Beat 1 into the frequency peak simply by using \(\nu=c/\lambda\)? The two spectra are densities per different horizontal intervals.

Beat 3 · Radiance or energy per volume

Run. Keep the temperature fixed while changing the plotted quantity; then inspect a cold example.

python main.py --T 5900 --quantity frequency
python main.py --T 5900 --quantity energy_density
python main.py --T 2.725 --quantity energy_density

Observe. Both frequency curves peak at the same \(x\) and physical frequency for a fixed \(T\), but their vertical axes and integrated units differ. Frequency radiance integrates to W m−2 sr−1; energy density integrates to J m−3. For isotropic black-body radiation, \(u_\nu=4\pi B_\nu/c\).

Your turn. Compare the first two physical integrals only after accounting for \(4\pi/c\). Do not compare the numbers as if they shared units.

Beat 4 · Add up a spectrum

Run. Compare both radiance representations at 5900 K.

python main.py --T 5900 --quantity wavelength
python main.py --quantity frequency --T 5900

Observe. The peak positions differ but both physical integrals should approach the same radiance, \(\sigma T^4/\pi\). The dimensionless shape is \(f_p(x)=x^p/(e^x-1)\), with \(p=5\) for wavelength radiance and \(p=3\) for the two frequency quantities. Their dimensionless areas therefore differ; their physical radiance integrals agree.

Your turn. Subtract the printed physical integral from its exact zero-to-infinity reference in each run. Which is closer? The emitted flux from a black surface is \(\pi\) times the integrated radiance; the printed radiance is not the emitted flux.

Beat 5 · Test the fourth power

Run. Record the physical integral in each mode at 3000, 6000 and 12000 K.

python main.py --T 3000 --quantity frequency
python main.py --T 6000 --quantity frequency
python main.py --T 12000 --quantity frequency
python main.py --T 3000 --quantity energy_density
python main.py --T 6000 --quantity energy_density
python main.py --T 12000 --quantity energy_density

Observe. Doubling the temperature multiplies a bolometric integral by \(2^4=16\) within numerical precision. The radiance reference is \(\sigma T^4/\pi\); energy density uses \(4\sigma T^4/c\).

Your turn. Take two successive ratios within each mode. Never divide an energy density by a radiance without the \(4\pi/c\) conversion.

Beat 6 · Change the sampling grid

Run. Keep the same physical model and vary the number of equal intervals in \(x\).

python main.py --n_steps 10 --T 5900
python main.py --n_steps 100 --T 5900
python main.py --n_steps 1000 --T 5900
python main.py --n_steps 2000 --T 5900
python main.py --n_steps 20000 --T 5900

Observe. There are \(N+1\) samples for --n_steps N. The ten-step peak is coarse, although the exact reference remains fixed. The sampled peak can lie as much as one grid step from the true maximum when the exact peak is inside the range and switches do not create a higher false maximum; a half-step bound is not guaranteed.

Your turn. Compare the first-line \(x\) values and the numerical-versus-exact integrals. Which converges more quickly? The area is a trapezoidal sum over a finite range.

Beat 7 · Move the approximation switches

Run. First keep both limiting approximations in the tails. Then move them into the body of the curve.

For comparison, the default settings are --x_low 0.05, --x_high 20.

python main.py --x_low 0.01 --x_high 100 --quantity wavelength
python main.py --x_low 1 --x_high 3 --quantity wavelength
python main.py --quantity frequency --x_low 1 --x_high 3
python main.py --x_low 5 --x_high 6 --quantity wavelength
python main.py --x_low 4 --quantity wavelength --x_high 20

Observe. Below --x_low the program uses the small-\(x\) Rayleigh–Jeans approximation; above --x_high it uses the large-\(x\) Wien approximation. The fourth and fifth commands can create a false maximum or a visibly distorted curve.

Your turn. For each run, compare its numerical integral with its exact reference, and look for a change in the reported peak. The exact value remains a fixed check for each temperature and quantity; moving the switches changes the numerical approximation.

Beat 8 · Cut off the range deliberately

Try a rejected command. python main.py --x_max 10 is expected to fail: the default --x_high 20 is now beyond the end of the range.

Run. Move both limits together, then cut below the wavelength peak; compare with a truncated low end and a full horizontal plot.

For comparison, the default settings are --x_min 0.01, --x_max 100, --x_low 0.05, --x_high 20, --y_frac_window 0.003.

python main.py --x_max 10 --x_high 9 --x_min 0.01 --x_low 0.05 --y_frac_window 0.003
python main.py --x_max 4 --x_high 3 --x_min 0.01 --x_low 0.05 --y_frac_window 0.003
python main.py --x_min 1 --x_low 1 --x_max 100 --x_high 20 --y_frac_window 0.003
python main.py --y_frac_window 0 --x_min 0.01 --x_max 100 --x_low 0.05 --x_high 20

Observe. The second command stops at \(x=4\), below the wavelength shape's true maximum near 4.965. The reported peak is at the edge and its numerical integral misses part of the spectrum. A window fraction of zero changes only the view, not the integration or peak calculation.

Your turn. Explain why the second physical integral departs from the exact reference. Valid settings require x_min ≤ x_low < x_high ≤ x_max. To isolate the viewing effect, compare the final command with Beat 0.

Two further challenges

After Beat 8. These optional tasks give you the programming investigations from the longer tutorial without changing the program files.

Challenge A: Solve the peak condition \(x=p(1-e^{-x})\) by repeatedly updating \(x\leftarrow p(1-e^{-x})\), starting at \(x=p\), for \(p=3\) and \(p=5\). Compare your answers with the first lines of these runs:

python main.py --quantity frequency --n_steps 100000
python main.py --n_steps 100000

Distinguish the continuous root from the sampled maximum.

Challenge B: In a Python interpreter opened in the program folder, run from planck2_driver import run_planck2, then r = run_planck2(5900.0, "wavelength", 2000). Compare r.coord_peak * r.T across temperatures and compute r.physical_integral / r.exact_physical_integral. Check against Beats 1 and 4. The result also exposes x_values, coord_values and y_values for your own plot.

Command-line parameters

All ordinary settings are command-line options described in main.py. Physical quantities are expressed in the International System of Units (SI). Options you omit return to their defaults on each run.

ParameterDefaultUnitsDescription
--T5900.0KPositive finite black-body temperature; the default approximates the Sun's continuum.
--quantity"wavelength"—"wavelength" plots radiance per wavelength; "frequency" plots radiance per frequency; "energy_density" plots energy density per frequency.
--n_steps2000—Number of equal \(x\)-intervals; the program samples n_steps + 1 points. Valid range: 1–1,000,000.
--x_min0.01—Positive lower bound of the dimensionless \(x\)-domain.
--x_max100.0—Upper bound of the dimensionless \(x\)-domain, greater than --x_min.
--x_low0.05—Below this value, use the small-\(x\) Rayleigh–Jeans approximation.
--x_high20.0—Above this value, use the large-\(x\) Wien approximation. Require x_min ≤ x_low < x_high ≤ x_max, so lowering --x_max below 20 also needs a lower --x_high.
--corner"upper_right"—Annotation location: upper_right, upper_left, lower_right or lower_left.
--y_frac_window0.003—Finite fraction of the peak used for plot windowing; 0 shows the full computed range. Does not affect the peak search or the integrals.

How to read the summary

Each successful run prints the version/build and sampled \(x\) peak, the physical peak wavelength or frequency, the dimensionless area beside its zero-to-infinity reference, the physical integral, and its exact bolometric reference. The plot annotation also shows the peak height. Compare numerical and exact physical integrals in the same quantity and units. The exact line describes an ideal zero-to-infinity integral; the numerical line uses your finite domain, grid and switch settings.

python main.py --version
python main.py --help

--version shows the shared code identifier. --help lists every option; these commands do not draw figures.
