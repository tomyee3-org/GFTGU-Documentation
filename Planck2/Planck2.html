Description

Planck2 is a black-body-radiation investigation. It plots the user's choice of spectral radiance per unit wavelength \(B_\lambda\), spectral radiance per unit frequency \(B_\nu\), or spectral energy density per unit frequency \(u_\nu\), using physical wavelength or frequency on the horizontal axis.

Besides the curve, the program prints and annotates the sampled peak, the area under the dimensionless shape function, and a physical integral over wavelength or frequency, next to the exact value that the integral would have if it ran from zero to infinity. Those last two numbers are what let you check the program, and the Stefan–Boltzmann \(T^4\) law, without any other tool.

The spine of the lesson is one sentence: every black-body spectrum is one universal curve \(x^p/(e^x-1)\) in the variable \(x=h\nu/kT\), so temperature only slides and scales it, the choice of what to call the spectrum (per wavelength, per frequency, or as an energy density) changes only the exponent \(p\) and the scale.

Model boundary: this is an ideal black body at one temperature. There are no spectral absorption lines, nonunit emissivity, or radiative transfer.

How to read the summary

Each successful run prints the version/build and sampled \(x\) peak, the physical peak wavelength or frequency, the dimensionless area beside its zero-to-infinity reference, the physical integral, and its exact bolometric reference. The plot annotation also shows the peak height. Compare numerical and exact physical integrals in the same quantity and units. The exact line describes an ideal zero-to-infinity integral; the numerical line uses your finite domain, grid and switch settings.

Beat 0 · Look at one spectrum

A body at 5900 K, about the temperature of the Sun's visible surface, glows across the spectrum but most strongly in one band. The following command plots spectral radiance per unit wavelength.

python main.py --T 5900 --quantity wavelength --n_steps 2000 --x_min 0.01 --x_max 100 --x_low 0.05 --x_high 20 --y_frac_window 0.003

The console gives peak at x = 4.959505, Peak wavelength = 4.917033e-07 m, and both a numerical and an exact integral. The plot box also gives the sampled Peak value, which the console does not. Compare 2.187105e+07 with 2.187106e+07 in W m−2 sr−1.

Move the cursor near the top of the curve. Which physical wavelength is at the maximum? Why might the cursor and the six-digit printed peak disagree slightly? Use the Zoom feature to magnify the top of the curve. Observe how the plot is drawn from short segments.

The dimensionless coordinate is \(x=hc/(\lambda kT)=h\nu/(kT)\). Planck's law supplies the curve; the printed peak is the largest sampled point, not a continuous optimizer.

Experiments that go with this beat: Experiment 1 in Suggested Experiments.

Beat 1 · Change temperature

Run the default spectrum at a cooler and a hotter temperature. The middle run is the default of Beat 0.

python main.py --T 3000
python main.py --T 5900
python main.py --T 10000

A hotter body peaks at a shorter wavelength. The product of temperature and peak wavelength should stay approximately fixed. The sampled \(x\) peak stays near 4.965 with a sufficiently fine grid.

Multiply the first and third peak wavelengths by their temperatures. How close are the products? The law for this plotted density follows from \(\lambda_{\rm peak}=hc/(x_5 kT)\), where \(x_5\approx4.965\).

Experiments that go with this beat: Experiment 1, Experiment 2 in Suggested Experiments, plus The Peak Condition by Iteration in Advanced programming challenges.

Beat 2 · Change the horizontal density

Radiation can be sorted by wavelength or by frequency. Ask for the same 5900 K body sorted by frequency, and then for the cold radiation that fills the universe.

python main.py --T 5900 --quantity frequency 
python main.py --T 2.725 --quantity frequency

These horizontal axes are in hertz; the second run represents the cosmic microwave background as an ideal 2.725 K black body. Its frequency peak is much lower. The frequency peak has \(x_3\approx2.821\), whereas Beat 1 used \(x_5\approx4.965\).

Calculate \(h\nu_{\rm peak}/(kT)\) from one printed frequency. Why is it wrong to turn the wavelength peak of Beat 1 into the frequency peak simply by using \(\nu=c/\lambda\)? The two spectra are densities per different horizontal intervals.

Experiments that go with this beat: Experiment 3 and Experiment 4 in Suggested Experiments.

Beat 3 · Radiance or energy per volume

The program has a third quantity, the energy stored in the radiation field. Run it beside the frequency radiance of Beat 2, and then at the temperature of the cosmic microwave background.

python main.py --T 5900 --quantity frequency
python main.py --T 5900 --quantity energy_density
python main.py --T 2.725 --quantity energy_density

The frequency and energy density curves peak at the same \(x\) and physical frequency for a fixed \(T\), but their vertical axes and integrated units differ. Frequency radiance integrates to W m−2 sr−1; energy density integrates to J m−3. For isotropic black-body radiation, \(u_\nu=4\pi B_\nu/c\).

Compare the first two physical integrals only after accounting for \(4\pi/c\). Do not compare the numbers as if they shared units.

Experiments that go with this beat: Experiment 3 and Experiment 5 in Suggested Experiments.

Beat 4 · Add up a spectrum

The Stefan–Boltzmann law is about what a black body radiates, and it comes from adding up the area under the spectrum. The program adds up two different areas, and it is easy to take the wrong one for the physical result. Run the wavelength curve and the frequency curve, and compare their printed integrals.

python main.py --T 5900 --quantity wavelength
python main.py --quantity frequency --T 5900

The peak positions differ but both physical integrals should approach the same radiance, \(\sigma T^4/\pi\). The dimensionless shape is \(f_p(x)=x^p/(e^x-1)\), with \(p=5\) for wavelength radiance and \(p=3\) for the two frequency quantities. Their dimensionless areas therefore differ; their physical radiance integrals agree.

Subtract the printed physical integral from its exact zero-to-infinity reference in each run. Which is closer? The emitted flux from a black surface is \(\pi\) times the integrated radiance; the printed radiance is not the emitted flux.

Experiments that go with this beat: Experiment 6 in Suggested Experiments, plus Read the Result Object in Advanced programming challenges.

Beat 5 · Test the fourth power

The integrated areas under the spectrum depend on the temperature as \(T^4\). Check that the program's sum does too, with three temperatures for each of the frequency quantities. Each run doubles the temperature of the one before.

python main.py --T 3000 --quantity frequency
python main.py --T 6000 --quantity frequency
python main.py --T 12000 --quantity frequency
python main.py --T 3000 --quantity energy_density
python main.py --T 6000 --quantity energy_density
python main.py --T 12000 --quantity energy_density

Doubling the temperature multiplies a bolometric integral by \(2^4=16\) within numerical precision. The radiance reference is \(\sigma T^4/\pi\); energy density uses \(4\sigma T^4/c\).

Take two successive ratios within each mode. Never divide an energy density by a radiance without the \(4\pi/c\) conversion.

Experiments that go with this beat: Experiment 6 in Suggested Experiments.

Beat 6 · Change the sampling grid

So far every run used the default grid of 2000 equal steps. The grid decides how well the sum follows the curve, and how well the peak is found. Change only --n_steps.

python main.py --n_steps 10 --T 5900
python main.py --n_steps 100 --T 5900
python main.py --n_steps 1000 --T 5900
python main.py --n_steps 2000 --T 5900
python main.py --n_steps 20000 --T 5900

There are \(N+1\) samples for --n_steps N. The ten-step peak is coarse, although the exact reference remains fixed. The sampled peak can lie as much as one grid step from the true maximum when the exact peak is inside the range and switches do not create a higher false maximum; a half-step bound is not guaranteed.

Compare the first-line \(x\) values and the numerical-versus-exact integrals. Which converges more quickly? The area is a trapezoidal sum over a finite range.

Experiments that go with this beat: Experiment 7 in Suggested Experiments.

Beat 7 · Move the approximation switches

The program does not evaluate \(x^p/(e^x-1)\) directly across the whole range. For very small \(x\), \(e^x-1\) is nearly \(x\); for very large \(x\), \(e^x\) is so big that the −1 does not matter, and the exponential would overflow. Two options set where the program switches: --x_low and --x_high. The first command below turns both switches off. The second and third move them inwards, the fourth moves them to the middle of the peak, and the fifth moves only the lower one to just below it.

For comparison, the default settings are --x_low 0.05, --x_high 20.

python main.py --x_low 0.01 --x_high 100 --quantity wavelength
python main.py --x_low 1 --x_high 3 --quantity wavelength
python main.py --quantity frequency --x_low 1 --x_high 3
python main.py --x_low 5 --x_high 6 --quantity wavelength
python main.py --x_low 4 --quantity wavelength --x_high 20

Below --x_low the program uses the small-\(x\) Rayleigh–Jeans approximation; above --x_high it uses the large-\(x\) Wien approximation. The fourth and fifth commands can create a false maximum or a visibly distorted curve.

For each run, compare its numerical integral with its exact reference, and look for a change in the reported peak. The exact value remains a fixed check for each temperature and quantity; moving the switches changes the numerical approximation.

Experiments that go with this beat: Experiment 8 in Suggested Experiments.

Beat 8 · Cut off the range deliberately

The defaults sample \(x\) from 0.01 to 100, which contains almost all of the curve. Change that range, and see how the summary shows what has been cut off. All four commands below satisfy the switch-ordering rule; each changes the sampled range or the view.

Move both limits together, then cut below the wavelength peak; compare with a truncated low end and a full horizontal plot.

For comparison, the default settings are --x_min 0.01, --x_max 100, --x_low 0.05, --x_high 20, --y_frac_window 0.003.

python main.py --x_max 10 --x_high 9 --x_min 0.01 --x_low 0.05 --y_frac_window 0.003
python main.py --x_max 4 --x_high 3 --x_min 0.01 --x_low 0.05 --y_frac_window 0.003
python main.py --x_min 1 --x_low 1 --x_max 100 --x_high 20 --y_frac_window 0.003
python main.py --y_frac_window 0 --x_min 0.01 --x_max 100 --x_low 0.05 --x_high 20

The second command stops at \(x=4\), below the wavelength shape's true maximum near 4.965. The reported peak is at the edge and its numerical integral misses part of the spectrum. A window fraction of zero changes only the view, not the integration or peak calculation.

Explain why the second physical integral departs from the exact reference. Valid settings require x_min ≤ x_low < x_high ≤ x_max. To isolate the viewing effect, compare the final command with Beat 0.

Suggested Experiments

The experiments are ranked from introductory to advanced, and each is cited by the beat it extends. Each command is run from the program's folder.

1 · Introductory — Solar Black-Body Approximation

Compare the sampled wavelength peak at 5900 K with Wien's displacement law. It should be near 490 nm. A real solar spectrum also has absorption lines, and the Sun's effective temperature is nearer 5800 K, which moves the peak to slightly longer wavelength.

python main.py --T 5900 --quantity wavelength

2 · Introductory — Wien's Displacement Law and Temperature

Verify that x_peak stays nearly constant while \(\lambda_{\rm peak}T\) stays near \(2.898\times10^{-3}\,\text{m K}\). Compare frequency peaks at different temperatures to see that they are proportional to \(T\).

python main.py --T 3000 --quantity wavelength
python main.py --T 5900 --quantity wavelength
python main.py --T 10000 --quantity wavelength
python main.py --T 3000 --quantity frequency
python main.py --T 10000 --quantity frequency

3 · Introductory — Cosmic Microwave Background

The 2.725 K frequency peak should be near 160 GHz. As an optional research extension, consider why the background's nearly ideal black-body spectrum supports a hot early universe.

python main.py --T 2.725 --quantity frequency

4 · Intermediate — Wavelength vs. Frequency Peaks

At the same temperature, record the \(B_\lambda\) peak wavelength, the \(B_\nu\) peak frequency, and \(c/\nu_{\max}\). The two wavelengths differ because the curves are densities with respect to different variables.

python main.py --T 5900 --quantity wavelength
python main.py --T 5900 --quantity frequency

5 · Intermediate — Frequency Radiance vs. Energy Density

Verify that x_peak and the peak frequency agree. Compare the plotted peak values and the printed physical integrals, and explain why their ratios equal \(4\pi/c\), with the corresponding change of units.

python main.py --T 5900 --quantity frequency
python main.py --T 5900 --quantity energy_density

6 · Intermediate — Stefan–Boltzmann T⁴ Scaling

Record the printed physical integrals, divide by T**4, and compare with \(\sigma/\pi\) for the radiance or \(4\sigma/c\) for the energy density. Doubling \(T\) should increase the integral by a factor of 16. Multiply the radiance integral by \(\pi\) to get the emitted flux \(\sigma T^4\) in W m−2.

python main.py --T 3000 --quantity frequency
python main.py --T 6000 --quantity frequency
python main.py --T 12000 --quantity frequency
# Repeat with --quantity energy_density to compare 4σ/c.

7 · Intermediate — Resolution and Peak Sampling

Compare the printed x_peak with the continuous wavelength peak \(x_5\simeq4.965114\), and compare the dimensionless area with its printed zero-to-infinity reference. For the physical integral, remember that its exact reference spans \(0<x<\infty\) while the numerical result uses the finite range. The sampled peak need not converge at the same rate as the trapezoidal area.

python main.py --n_steps 10
python main.py --n_steps 100
python main.py --n_steps 1000
python main.py --n_steps 2000
python main.py --n_steps 20000

8 · Intermediate — Rayleigh–Jeans and Wien Limits

Compare the default peak and integrals with a run that applies the small- and large-\(x\) approximations well beyond their usual regimes. These thresholds change the approximation regions while preserving the physical range. Then try moving only one of the two thresholds.

python main.py
python main.py --x_low 1 --x_high 3

9 · Intermediate to Advanced — Truncating the Range

Use the dimensionless shapes in Beat 4 to predict which tails each printed integral will lose when the range is cut at \(x_{\max}=10\), then run it and compare. Repeat with \(x_{\min}=1\) and with \(x_{\max}=4\), and compare the fractional loss of the dimensionless area with that of the physical integral. With the same x-grid and switches, all three physical integrals have the same fractional truncation loss after their unit conversions; the wavelength shape area has a different weighting. Explain why a peak inside the retained range does not warn you about missing tails.

python main.py --x_max 10 --x_high 9
python main.py --x_max 4 --x_high 3
python main.py --x_min 1 --x_low 1

Advanced programming challenges

The Peak Condition by Iteration — Advanced Programming

Determine the spectral peak by repeating \(x\leftarrow p(1-e^{-x})\) and compare the roots with the sampled peaks of a very fine grid. The script imports the driver directly, so run it from the program's folder.

import math
from planck2_driver import run_planck2

for quantity, p in (("wavelength", 5), ("frequency", 3)):
    x = float(p)
    for _ in range(50):
        x = p * (1.0 - math.exp(-x))
    sampled = run_planck2(5900.0, quantity, 100000).x_peak
    print(quantity, x, sampled)

Read the Result Object — Advanced Programming

Every number the summary prints, and the whole curve, is available from the result of run_planck2(). Compute \(\lambda_{\rm peak}T\) and the ratio of the physical integral to its exact reference without opening a plot, and compare them with Beats 1 and 4.

from planck2_driver import run_planck2

r = run_planck2(5900.0, "wavelength", 2000)
print(r.coord_peak * r.T)
print(r.physical_integral / r.exact_physical_integral)

Restoring Defaults and Program Files

A new run with python main.py uses all default settings; options in a previous command do not carry over. If you edit main.py or another program file for an exercise, restore it using any of the following methods:

  • Same session: Press Ctrl+Z (Windows) or Cmd+Z (macOS) repeatedly in your editor to undo your edits.
  • If you are using PyCharm: Right-click the edited file in the Project panel → Local History → Show History → select a version from before your changes → click Revert.
  • Full reset: Re-download the ZIP from github.com/tomyee3-org/GFTGU-Programs and replace this program's folder with the fresh copy.

For additional ways to restore program files, see the corresponding recovery instructions in the GFTGU Python Setup Guide.

Command-line parameters

All ordinary settings are command-line options described in main.py. Physical quantities are expressed in the International System of Units (SI). Options you omit return to their defaults on each run.

ParameterDefaultUnitsDescription
--T5900.0KPositive finite black-body temperature; the default approximates the Sun's continuum.
--quantity"wavelength"—"wavelength" plots radiance per wavelength; "frequency" plots radiance per frequency; "energy_density" plots energy density per frequency.
--n_steps2000—Number of equal \(x\)-intervals; the program samples n_steps + 1 points. Valid range: 1–1,000,000.
--x_min0.01—Positive lower bound of the dimensionless \(x\)-domain.
--x_max100.0—Upper bound of the dimensionless \(x\)-domain, greater than --x_min.
--x_low0.05—Below this value, use the small-\(x\) Rayleigh–Jeans approximation.
--x_high20.0—Above this value, use the large-\(x\) Wien approximation. Require x_min ≤ x_low < x_high ≤ x_max, so lowering --x_max below 20 also needs a lower --x_high.
--corner"upper_right"—Annotation location: upper_right, upper_left, lower_right or lower_left.
--y_frac_window0.003—Finite fraction of the peak used for plot windowing; 0 shows the full computed range. Does not affect the peak search or the integrals.
