Release Status

These notes cover Version 1.5.1 and the two code-changing rounds that produced it: the Audit 23 response (1.5.0) and the Audit 24 response (1.5.1). Audit 25 changed nothing and only reviewed 1.5.1. Versions 1.2.0 to 1.5.0 were never released separately; the last published notes were for 1.1.0.

  • Codex, Audit 25: no change to the program or the Help required. No hold.
  • Grok, Audit 25: accept 1.5.1; no new defect. No hold. Grok notes that relabelling the release 1.6.0 is an optional house decision, because the 1.5.1 change is a visible plot change.

Major Improvements in This Release

Version 1.5.1 (Audit 24 response):

  • The plot's vertical axis now starts at zero in every mode; it previously extended about 5% of the peak below zero.
  • The Help no longer claims that the sampled peak is within half a grid step of the true peak; it states the one-step bound and that the nearest grid point is not always the one selected.

Version 1.5.0 (Audit 23 response):

  • A grid whose neighbouring points convert to the same wavelength or frequency is rejected with advice to widen the range or lower --n_steps; previously it could produce a plot with no horizontal extent.
  • The Help's Beat 7 names the fourth and fifth runs correctly, and the Help describes the overflow-safe evaluation used above x = 700.

Also new in the unreleased 1.2.0 to 1.4.0 steps:

  • The console summary has a second line, Peak wavelength = ... m or Peak frequency = ... Hz (1.3.0). The other four lines and their numbers are unchanged.
  • New Beats tutorial Help, Planck2-claude.html, with nine beats and 11 experiments; the Reference Guide Help is retained as Planck2-original.html (1.2.0).
  • The Help distinguishes the printed radiance integral (W m-2 sr-1) from the emitted flux, which is π times it (1.3.0).
  • With --y_frac_window 0 the horizontal axis ends at the first and last computed wavelength or frequency instead of extending to negative values (1.2.0).
  • An out-of-order domain now reports the four values it was given, for example --x_max 10 alone (1.2.0).
  • Runs with --x_high above about 710 complete instead of stopping with OverflowError (1.4.0).
  • A grid whose points are not distinct in floating point is rejected with advice (1.4.0).
  • Labels, units, exponents and prefactors of the three quantities come from one read-only descriptor, QuantitySpec, and the parser is available as build_parser() (1.2.0, 1.3.0).

Known Limitations

  • An ideal black body at one temperature; no absorption lines, emissivity below one or radiative transfer.
  • Integrals are trapezoidal sums over a finite x-range; the default results differ from the exact values by less than 10-6.
  • The printed peak is the largest grid sample, within one grid step of the true peak only for the exact curve on a range that contains it.
  • Moving --x_low or --x_high into the curve can create false maxima and wrong integrals by design; the exact reference line is the check.
  • The physical integral of the radiances is integrated radiance, not emitted flux.
  • The equations in the Help are typeset by MathJax and need an internet connection.

Known Minor Maintenance Items

  • MathJax is not bundled for offline use; this awaits a decision for the whole program set.
  • The Related Programs links point to Star.html and Random2.html and will need updating if those Help files are renamed.
  • Planck2-original.html and Planck2-claude.html are both present, and neither is marked as the current Help.
  • Planck2-claude.html is the Claude-style Help, which quotes run results; the Grok-style alternative is a separate file not yet written.
  • The annotation prints the peak x to four decimals and the console to six.
  • The --help text for --x_max does not mention that --x_high must not exceed it.
  • There is no option to save a figure to a file.
