Star 1.1.0 Release Notes

Version: 1.1.0
Build: 35c2e676d666
Date: 2026-09-16

Release Summary

Star 1.1.0 adds a complete command-line interface and a five-significant-digit stellar-structure summary. The underlying Newtonian polytropic integration, default physical model, surface treatment, and plots retain their established behavior.

Command-Line Interface

  • --p_c, --T_c, --mu, and --gamma set the physical inputs. The parser requires positive finite values and requires gamma > 1.2.
  • --max_points and --steps_per_scale expose both driver controls, including the defaults that were previously assigned only in main.py.
  • --output_type selects pressure, density, temperature, or mass; each alternative and its units are described in main.py and Help.
  • --log_y requests a logarithmic vertical axis. The entry point rejects its use with mass because enclosed mass is zero at the center.
  • --help prints descriptions and defaults, while --version prints the synchronized version and reproducible Build ID.

Printed Structure Summary

  • Every run prints the modeled surface radius and total mass in SI units.
  • Pressure, density, temperature, and mass enclosed are printed at 0%, 25%, 50%, 75%, and 90% of the modeled surface radius.
  • Checkpoint values are evaluated by linear interpolation between adjacent stored radial points rather than choosing a nearby grid point.
  • All reported numerical values use five significant figures. The selected plot does not change the printed structure summary because every integration computes all four profiles.

Documentation and Verification

  • The Help file now includes a command-line quick start, full option table, selector explanations, and commands for all parameter-only suggested experiments.
  • The multi-region equation-of-state exercise remains explicitly identified as a programming extension that cannot be completed by changing command-line inputs alone.
  • The Sample Outputs Guide includes the complete default console summary and command-line equivalents for all four embedded figures.
  • The regression suite now contains 74 tests covering command defaults and forwarding, input rejection, all output selectors, log-axis behavior, checkpoint locations and interpolation, five-significant-digit output, Help synchronization, numerical physics, and Build-ID reproduction.
  • The packaged-layout Help lookup now supports the documented sibling 08-Star directory as well as a flattened upload.

Example Commands

python main.py
python main.py --output_type density --log_y
python main.py --T_c 2.4893e7 --steps_per_scale 800 --max_points 4000
python main.py --mu 1 --gamma 2 --p_c 1.9888e34 --T_c 1.1188e12 \
    --max_points 5000 --output_type mass

Known Limitations

  • Star is intended for education and conceptual exploration, not research-grade stellar modeling.
  • The model is Newtonian, spherically symmetric, and governed by one polytropic equation of state. It omits energy generation and transport, composition gradients, rotation, magnetic fields, and relativistic gravity.
  • The default parameters reproduce approximately the Sun's total mass and radius but do not constitute a high-accuracy solar-interior model.
  • The forward-Euler integrator has first-order global accuracy. Increasing --max_points does not refine an already successful run; refinement requires increasing --steps_per_scale while preventing a restart.
  • The step-doubling restart increases radial coverage at the cost of resolution and is not an error-controlled adaptive integrator.
  • The modeled surface and the newly reported interior checkpoints use linear interpolation. The fractional surface shell retains the forward-Euler left-endpoint density and is first-order accurate.
  • The red-giant and neutron-star exercises are schematic. Real neutron-star calculations require dense-matter equations of state and general relativity.
  • The Help file uses MathJax from a public CDN for typeset equations; prose and raw equation source remain readable offline.
