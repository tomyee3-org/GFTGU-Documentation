Major Improvements in This Release

Version 1.7.0 (Audit 22 response):

  • The summary prints final specific energy, the specific energy of the last accepted state.
  • --maxOrbits below 1e-9 is now rejected with an error. Previously a tiny target such as 1e-13 overshot by a factor of 2 and 1e-16 by a factor of 204, and still printed closure residuals.
  • Small --maxOrbits targets are now met to a small fraction of the request. This changes the printed azimuthal revolutions and end state for targets below about 0.16; runs with larger targets, including the default, print the same numbers as before.
  • Closure residuals are printed only when --maxOrbits is a whole number of at least 1.
  • With no accepted step, the shortest and longest accepted step lines both read n/a (no step accepted).
  • The initial-velocity marker on the hodograph is larger and red, with a black edge.

Version 1.6.0 (Audit 21 response):

  • The summary prints acceleration evaluations, shortest accepted step and longest accepted step.
  • The Keplerian block prints specific energy of the starting state.
  • The hodograph plot marks the origin (zero velocity) and the initial velocity.
  • New Beats tutorial Help, Orbit-claude.html, with nine beats and 15 experiments; the Reference Guide Help is retained as Orbit-original.html.

Also new in the unreleased 1.5.0 step:

  • Five-significant-digit output no longer prints six digits at a rounding boundary (for example 0.99999996 now prints as 1.0000, not 1.00000).
  • An invalid --k is reported as k, not mu.
  • The nine numerical limits and factors of the integrator are named constants in driver_orbit.py, and the termination reason is a TerminationReason value with unchanged text.

Test Suite Growth

  • 1.4.0: 75 tests. 1.5.0: 128. 1.6.0: 144. 1.7.0: 156 (149 in the Audit 22 response, plus seven checks of these two documents).
  • Run from the program folder with python -m unittest discover -s tests. In the full repository layout all 156 tests run and pass with no skips. In a flat folder that lacks the documentation files, the tests that read the Release Notes, the Sample Outputs Guide and Orbit-original.html are skipped (13 skips), and the rest pass.
  • New coverage since 1.4.0 includes every command shown in the Help, the numbers the Help quotes, the named constants, small --maxOrbits targets, and the version and build in both companion documents.

Known Limitations

  • Planar Newtonian motion of a test particle about a fixed point mass; no relativity, drag, tides or second body.
  • The Mercury-like defaults are a teaching state, not an ephemeris.
  • Closure residuals are defined only for a whole number of revolutions.
  • The angular-step safeguard is a conservative estimate, not a proof.
  • The equations in the Help are typeset by MathJax and need an internet connection.

Known Minor Maintenance Items

  • Four groups of numerical literals in run_orbit() are not yet named constants.
  • There is no option to save a figure to a file.
  • The physics functions still name the gravitational parameter mu in their error messages.
  • There is no runtime check that the final azimuth matches --maxOrbits; tests cover the accepted range.
  • Orbit-original.html and Orbit-claude.html are both present, and neither is marked as the current Help.
  • Grok Audit 21 items P4 to P6: the spine sentence has three claims, Beat 0 answers its own question, and the Printed Summary reproduces the whole default console.
