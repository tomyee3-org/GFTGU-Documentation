The evening at the terminal

Tonight you will grow a spherical star from its centre until its pressure reaches zero. The program uses Newtonian gravity and a single pressure–density power law, called a polytrope. It prints a radius, a mass, an integration grid, and a more accurate Lane–Emden numerical reference for the same equations. Each run opens one radial profile in Matplotlib.

Open a terminal in the folder containing main.py. Run the commands below in order, read the named lines, and close each plot window before the next run. All quantities use the International System of Units (SI). Use Python 3.10 or later with Matplotlib installed. No network is needed to run the program; the equations on this page use MathJax from a public content delivery network.

The default radius and mass are close to the Sun's, but this is a teaching polytrope: it has no energy generation, radiation or convection, composition gradient, or relativistic gravity. Its surface temperature of zero is a feature of the model, not a claim about the Sun.

Beat 0 · Find the surface

Start with the default pressure profile.

python main.py --p_c 7.158e+15 --T_c 22630000 --mu 1.285 --gamma 1.36 --steps_per_scale 400 \
  --max_points 2000 --output_type pressure

Read Radius (m) and Total mass (kg): about 6.9674e+08 m and 1.9825e+30 kg. The plotted pressure starts at 7.158e+15 Pa and reaches zero at that radius. Hover over the curve to read a pressure at a chosen radius. Why does pressure have to rise inward? The gas at each radius supports the weight of the gas above it.

\[\frac{dp}{dr}=-\frac{Gm(r)\rho(r)}{r^2},\qquad \frac{dm}{dr}=4\pi r^2\rho(r).\]

Here m(r) is the mass inside radius r, and ρ(r) is density. The exterior shells exert zero net pull at that radius. The program advances these two relations outward in finite radial steps; its pressure reaching zero defines the surface.

Beat 1 · Reveal the outer gas

python main.py --output_type density --log_y

The vertical scale is logarithmic, so small positive densities near the surface become visible. Find the density near half the radius, about 2313 kg/m³, and near 0.9 of the radius, about 6.65 kg/m³. The exact zero at the surface cannot appear on a logarithmic axis. The summary's central density is about 49187 kg/m³.

The program fixes the central density from the ideal gas relation, then uses the same polytropic relation everywhere: \(p=K\rho^\gamma\), with default exponent \(\gamma=1.36\). What happens to density as pressure falls? Try to predict the plot before reading the next run.

Beat 2 · Read a temperature

python main.py --output_type temperature

Use the cursor and the printed 50% checkpoint to find roughly 7.53e+06 K at half the radius; compare with 2.263e+07 K at the centre. The program obtains temperature from pressure and density through \(p=\rho k_B T/(\mu m_p)\), with \(\mu\) the mean particle mass in proton-mass units. It does not calculate energy transport. Why is this temperature curve less steep than the pressure curve?

Beat 3 · Locate the mass

python main.py --output_type mass

Check the 50% radius row of the interior checkpoints: about 1.6732e+30 kg is already enclosed, roughly 84% of the total. At 75% of the radius the enclosed mass is about 99% of the total. The curve flattens outward because density falls. Estimate from the curve where half of the mass lies; it is well inside half the radius.

Beat 4 · Stretch a star

For comparison, the default settings are --T_c 22630000.

python main.py --T_c 2.4893e7 --p_c 7.158e+15

This central temperature is 10% above the default, while central pressure is unchanged. Compare the new radius 7.6641e+08 m and mass 2.3988e+30 kg with Beat 0. The ratios are about 1.10 and 1.21. For this specific change with the other inputs fixed, the radius scales with central temperature and the mass with its square. The pressure profile keeps its shape when radius is measured as a fraction of the new surface radius.

Check the Restarts line before comparing numerical errors across runs: a restart doubles the step.

Beat 5 · Check a solvable case

For comparison, the default settings are --gamma 1.36.

python main.py --gamma 2

The printed polytropic index \(n=1/(\gamma-1)\) is now 1. This Lane–Emden case has the known profile \(\theta(\xi)=\sin(\xi)/\xi\), whose first zero is \(\xi=\pi\). Read the printed Lane–Emden radius, about 2.6392e+08 m, beside the program's stepwise radius, 2.6239e+08 m. The stepwise radius is about 0.58% smaller. The Lane–Emden number is a numerical reference for the same model, not an observation of a real star.

Beat 6 · Halve the step

For comparison, the default settings are --steps_per_scale 400, --max_points 2000.

python main.py --steps_per_scale 800 --max_points 4000

Compare Radial step (m) with Beat 0: about 2.6323e+05 m instead of 5.2645e+05 m. There are 2666 grid points and no restarts. The integrated radius now differs from the Lane–Emden radius by about -0.0075071, versus -0.014174 in Beat 0; the mass difference is -0.00092707, versus -0.0018494. The first-order Euler integration error roughly halves. The two pressure plots look almost the same; use the printed differences to see the change.

The Lane–Emden reference is calculated independently with a higher-accuracy method, but both calculations implement the same physical assumptions. Its step-halving uncertainty is an estimate, not a guaranteed bound.

Beat 7 · Catch a restart

For comparison, the default settings are --max_points 2000.

python main.py --max_points 1000 --steps_per_scale 400

Read Restarts (radial step doubled): 1. The program could not reach the surface inside the requested 1000-point capacity at its initial step, so it began again with twice the radial step. It finished with 654 points. Compare the -0.02726 radius difference with the default -0.014174; the coarser integration is less accurate. Raising --max_points can prevent a restart, while raising --steps_per_scale directly requests a smaller initial step.

Beat 8 · Approach the limit

For comparison, the default settings are --gamma 1.36.

python main.py --gamma 1.21

The index is about 4.7619, close to the finite-radius boundary at \(n=5\), or \(\gamma=6/5\). The integrated radius is about 7.2406e+09 m, while the Lane–Emden radius is about 9.9626e+09 m: a -0.27322 relative difference after four restarts. Almost all the mass lies in the inner part of this enormous, thin-envelope model. The plot alone hides much of the numerical difficulty.

For a deliberately extreme case, run:

python main.py --gamma 1.2000000001

Look for the warning about the Lane–Emden uncertainty and the printed index 4.9999999975. The integrated radius is unreliable here. The program rejects exactly \(\gamma=1.2\), because this single-polytrope model has no finite surface at that boundary.

python main.py --gamma 1.2

The final command should exit with an input error, not produce a plot.

Parameters

All settings are command-line options described in main.py. --output_type and --log_y change only the plot; the printed summary is the same whichever profile is plotted.

ParameterDefaultDescription
--p_c7.158e15Positive central pressure in pascals.
--T_c2.263e7Positive central temperature in kelvin.
--mu1.285Positive mean particle mass in proton-mass units; an effective model value.
--gamma1.36Polytropic exponent γ in p = Kργ; must exceed 1.2 for finite radius.
--max_points2000Grid-point capacity per attempt, an integer from 3 to 1000000. Exceeding it restarts at twice the step.
--steps_per_scale400Positive integer steps per characteristic radial scale; more means a finer initial step.
--output_type"pressure"Plot pressure, density, temperature, or enclosed mass.
--log_yFalseMake the vertical scale logarithmic; incompatible with a mass plot because mass starts at zero.

For option syntax, run python main.py --help. To see the release identifier without opening a plot, run python main.py --version.

What to carry away

Pressure balances gravity and a chosen pressure–density law closes the model. The radius, mass, and profiles follow from the central conditions, but different numerical steps give different approximations. Always read the actual step, restarts and Lane–Emden comparison before interpreting a close-looking plot. The reference is a check on the integration of these equations, not a check on whether a real star obeys them.
