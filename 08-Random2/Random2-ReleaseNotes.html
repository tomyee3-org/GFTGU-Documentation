Random2 1.2.0 Release Notes

Version: 1.2.0
Build: 5dc294ca595d
Date: 2026-09-16

Release Summary

Random2 1.2.0 adds a complete command-line interface for the existing scaled-distance and two-dimensional star experiments. Every ordinary input formerly assigned in main.py, including defaults inherited from the driver and plotter, now has a documented command-line option. The numerical models and default calculations are unchanged.

Command-Line Interface

  • --display {scaled_distance,walk2d} selects the 3D statistical scaling experiment or the fixed-step 2D star visualization.
  • --max_steps, --n_trials, and --step_distribution {uniform,gaussian} control the scaled-distance experiment. The former spellings --maxSteps and --nTrials are accepted as compatibility aliases.
  • --reference_steps, --n_walks, --mean_free_path, --radius_factor, --radius, --ray_length_factor, and --step_cap control the 2D visualization.
  • --corner accepts the command-safe selector values upper_right, upper_left, lower_right, and lower_left. The entry point translates these values to the plotter's internal spaced labels.
  • Positive integer, positive finite, and nonnegative finite option types reject invalid inputs before a simulation starts. --help displays descriptions and defaults; --version prints the synchronized version and Build ID.

Documentation and Verification

  • The Help file now includes a command-line quick start, a complete option table, selector explanations, and runnable commands for all parameter-only suggested experiments.
  • The programming extension remains identified as requiring a source change; the Help file does not imply that input options can perform an algorithmic modification.
  • The Sample Outputs Guide now pairs each representative result with the equivalent main.py command and explains that fixed illustration seeds require a short Python reproducibility harness because seed selection is not a program input.
  • Regression coverage now checks command defaults, selector parsing, input rejection, forwarding to both drivers, corner translation, version/build synchronization, and the packaged documentation path.

Default Commands

python main.py
python main.py --display scaled_distance --step_distribution gaussian
python main.py --display walk2d --n_walks 6 --radius 50 --corner lower_left

Known Limitations

  • Random2 is an educational diffusion model, not a research-grade model of stellar radiative transport.
  • The scaled_distance uniform-component construction fills a cube and is not directionally isotropic, though its independent zero-mean finite-variance components retain the intended square-root scaling.
  • The walk2d display is planar. Its first-passage distribution is not the corresponding three-dimensional stellar distribution.
  • Monte Carlo output varies between runs. Larger trial or walk counts reduce sampling noise but increase run time and, for displayed paths, memory use.
  • A path that reaches --step_cap is censored and marked with an x. Quantitative escape-time work should verify that nearly all paths escape.
  • Computing fitted slopes, exporting individual escape-step data, or changing the definition of scaled distance still requires a programming change.
  • The Help file uses MathJax from a public CDN for typeset equations. Its prose and raw equation source remain readable offline.
