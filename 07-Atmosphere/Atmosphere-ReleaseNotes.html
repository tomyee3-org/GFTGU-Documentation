Atmosphere 1.2.0 Release Notes

Version: 1.2.0
Build: 94d7d42087d2
Date: 16 September 2026

Release summary

Version 1.2.0 adds a complete command-line interface and prints pressure, p/T, and temperature at every supplied atmosphere checkpoint. The atmospheric integration, default hybrid Earth profile, and plot rendering remain numerically compatible with version 1.1.1.

Command-line inputs

  • Added --planet_name, --g_accel, --mu, and --p0 for the atmosphere label, constant gravity, mean molecular weight, and reference pressure.
  • Added --h_points and --T_points for comma-separated altitude and temperature profiles. The model continues to require equal list lengths, strictly increasing finite altitudes, and positive finite temperatures.
  • Added lowercase command selectors --output_type pressure, density, and temperature, mapped to the driver’s legacy capitalized values.
  • Retained --version and added current defaults to --help.
  • Expanded the main.py module description with the meaning, units, accepted forms, and physical effect of every input.

Printed checkpoint results

  • Every run prints one row for every altitude supplied through --h_points, independently of the plot selector.
  • Each row contains interpolated pressure in pascals, p/T in Pa/K, and the paired defining temperature in kelvin.
  • Pressure is linearly interpolated between adjacent stored integration samples; temperature comes directly from the supplied checkpoint profile.
  • Custom checkpoints outside the stored positive-pressure integration domain remain visible and are marked unavailable for pressure and p/T.
  • Checkpoint numerical values are formatted to five significant figures.

Driver and documentation additions

  • Added immutable CheckpointData rows and extract_checkpoints() for validated, reusable checkpoint extraction.
  • Reworked Quick Start, parameter tables, selector descriptions, and non-programming exercises around command-line examples following the StellarEvolutionTracks pattern.
  • Added a Printed Checkpoints section with the table definition, interpolation behavior, units, precision, and unavailable-value policy.
  • Updated the Sample Outputs Guide with the complete default 15-checkpoint transcript and current command examples.
  • Corrected the portable Help-file regression lookup so the tests support the actual packaged program-plus-documentation layout.

Verification

The regression suite now contains 82 tests. New coverage verifies every command-line model input, lowercase selector mapping, comma-separated profiles, all default checkpoints, exact surface pressure, pressure interpolation, p/T, out-of-domain rows, malformed result rejection, console headings, Help parameters, and packaged documentation discovery. Existing analytic, randomized, boundary, plotting, and Build-ID tests remain in place.

Known limitations

  • Atmosphere is an educational constant-gravity, constant-composition ideal-gas model, not an operational atmosphere forecast.
  • The first-order Euler method accumulates discretization error. An unusually extended profile that exhausts the 50,000-point budget restarts with a larger step.
  • The upper continuation T = βp0.5 is a pedagogical closure, not a realistic exospheric-temperature law.
  • The rounded 100–500 km NRLMSIS 2.0 temperatures are illustrative and specific to the documented date, location, and activity conditions.
  • A checkpoint outside the computed positive-pressure domain has no model pressure or p/T; the report identifies this explicitly.
  • The Help file uses MathJax from a public CDN. Offline, formulas remain visible as TeX source but are not typeset.

Atmosphere 1.1.1 Release Notes

Version: 1.1.1
Build: 58b6ba9b3808
Date: 2026-08-27

Release Status

Version 1.1.1 concludes a kickoff maintenance review followed by two rounds of independent review involving Codex, Copilot, and Gemini. The reviewers verified the governing physics, numerical results, error handling, Help-file accuracy, Version/Build synchronization, and regression coverage. No release-blocking or medium-severity defect remains. The program is approved as sufficiently robust and accurate for student use, with the idealizations and minor maintenance items listed below.

Major Improvements in This Release

  • Expanded the integration budget from 1,000 to 50,000 points so the default 500 km Earth profile retains the intended H/200 Euler step instead of silently restarting at much coarser resolution.
  • Corrected the resulting pressure error: the former coarse calculation was approximately 53% low near 100 km and almost a factor of three low near 500 km.
  • Added comprehensive validation for finite and physically valid pressures, temperatures, densities, gravity, mean molecular weight, surface pressure, and temperature-profile data.
  • Added explicit overflow, underflow, altitude-step, retry-limit, and zero-pressure boundary protection.
  • Corrected evaluation of the altitude-zero reference temperature for profiles that begin above zero or span zero altitude.
  • Corrected state handling so a zero-pressure upper-profile query cannot corrupt a later positive-pressure calculation.
  • Added clear, student-facing error messages for invalid parameters and model failures.
  • Documented the 50,000-point coverage mechanism, non-positive pressure boundary, numerical limitations, result metadata, and Version/Build identification.
  • Retained and verified nine exercises arranged from introductory output exploration through an advanced height-dependent-gravity extension.
  • Added BUILD_ID provenance across the four core program modules and synchronized it with the Help file and runtime output.

Test Suite Growth

58 → 72 automated tests across the audit process, including 120 fixed-seed randomized model/profile cases.

The final suite verifies equations, interpolation, validation, boundary behavior, build hashing, newline independence, default numerical regressions, ideal-gas consistency, analytic isothermal and linear-lapse solutions, a refined multilayer benchmark, successful restart equivalence, repeated-run stability, command-line behavior, Help metadata, and plotting. All 72 tests pass in both the canonical tests/ layout and a flattened upload layout.

Known Limitations

  • Intended for education and conceptual exploration rather than operational atmospheric prediction or research-grade atmospheric modeling.
  • Gravity and mean molecular weight remain constant with altitude; the model does not reproduce species-by-species diffusive equilibrium in the upper atmosphere.
  • The first-order Euler method accumulates discretization error. Unusually extended profiles that exhaust the 50,000-point budget restart with a larger step and therefore have greater numerical error.
  • The upper-atmosphere continuation T = βp0.5 is a pedagogical closure that drives temperature toward zero; it is not a realistic exospheric-temperature law.
  • The rounded 100–500 km NRLMSIS 2.0 temperatures are illustrative and specific to the stated date, location, and activity conditions. The archived CCMC Instant Run output is not included with this release.
  • Extreme parameter combinations can exceed the supported floating-point domain and are rejected with explanatory errors.

Known Minor Maintenance Items

  • Direct API callers should not mutate h_points or T_points after constructing AtmosphereModel; the normal main.py workflow does not do so. A future revision may defensively snapshot or revalidate these sequences.
  • The Help file's explicitly abbreviated main.py excerpt omits the planet name and output type from its example status line, although the delivered program prints both.
  • Future test-suite hardening may add broader generated edge-profile families and focused assertions for additional critical Help-file statements. Existing deterministic tests cover the documented student workflows and principal boundary cases.
